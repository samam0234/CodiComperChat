# 코디컴퍼챗 포트폴리오
이 사이트는 1인 풀스택 프로젝트 「코디컴퍼챗」을 프론트엔드 · 운영 콘솔 · 백엔드 · AI 서비스 네 층으로 나눠 소개하는 포트폴리오입니다. 각 층이 무엇을 맡고, 어떤 판단으로 만들었고, 어디서 막혔으며, 앞으로 무엇을 할지를 숫자와 화면으로 보여 드립니다.
기간: 2026-09-15 ~ 2026-11-08 (약 8주) · 1인 개발 (기획 · 프론트 · 백엔드 · AI · 배포)

## 프로젝트 한 줄
유저가 주인공인 이야기를, 성격이 흔들리지 않는 AI 캐릭터가 함께 이어 가는 웹 서비스. 대화를 닫았다 다시 열어도 캐릭터가 지난 일을 기억하고, 관계가 쌓이고, 숨겨 둔 비밀과 부탁이 때가 되면 드러난다.

## 해결한 문제
- 긴 대화가 쌓이면 앞일을 잊는다 → 기억 · 요약 · 친밀도 · 복선을 따로 저장하고 필요한 만큼만 넣는다
- 없는 개인사를 지어낸다 → 설정에 근거가 없으면 단정하지 않게 막고, 지어냈으면 다시 쓴다
- 비밀을 유도하면 털어놓는다 → 비밀을 모델에 아예 보내지 않는다
- 대화 말고는 할 게 적다 → 속마음 · 일기 · 문자 · 게시판 · 장면 그림 · 웹툰으로 넓어진다
- 캐릭터는 프롬프트 한 덩어리 → 8단계 카드와 3턴 테스트를 통과해야 발행된다
- 한 번에 한 캐릭터와만 → 월드코퍼챗: 한 세계관의 여러 인물과 파트 · 지도 · 미니게임으로

## 프론트엔드 — 이용자 웹
화면 35개의 Next.js 16 이용자 사이트. 판단은 하지 않고, 읽기는 서버 컴포넌트, 쓰기는 서버 액션으로 Nest만 부른다. 세션 토큰은 브라우저가 모른다. 1:1 답만 일회용 표로 Nest 웹소켓에 붙고, 그 소켓은 글을 옮길 뿐 추론을 나누지 않는다.

### 프론트엔드 — 이용자 웹 — 개요
이용자가 캐릭터를 둘러보고, 대화하고, 공방에서 캐릭터를 만들고, 월드코퍼챗을 플레이하는 웹이다. 화면은 35개, 묶음은 둘러보기 · 대화 · 오퍼레이션 · 공방 · 월드 · 내 것 · 계정 · 요금 · 안내 아홉 갈래다.
- 서버 컴포넌트가 lib/*.ts(server-only)로 읽고, 클라이언트는 app/actions/*.ts 서버 액션으로 쓴다
- 로그인 토큰은 httpOnly 쿠키에만 있고 서버 코드가 Authorization 헤더로 붙인다 → CORS를 열지 않는다
- 운영 배포: Vercel(icn1), API는 Oracle VM의 Caddy 뒤

### 프론트엔드 — 이용자 웹 — 사용 엔진
- 프레임워크: Next.js 16 (App Router · 서버 컴포넌트 · 서버 액션)
- UI: React 19 · TypeScript · CSS Modules
- 스타일: 디자인 토큰(app/globals.css) — 라이트 · 다크, 한국 시각에 따라 자동 전환
- 보안: proxy.ts가 요청마다 nonce CSP 발급, 외부 스크립트는 결제창 하나뿐
- 시험: Playwright E2E 123개(운영 빌드 + 가짜 LLM · 가짜 그림 엔진)

### 프론트엔드 — 이용자 웹 — 상세 기능
- 대화: 기억 · 지난 이야기 · 상태 설정 · 엑스트라 · 모델 고르기 · /다시 /계속 /되돌리기 명령어 · *행동* 과 @: 나레이션 꾸미기 · 대답 추천
- 오퍼레이션: 심리 탐구(속마음) · 일기 · 문자 · 가상 게시판 · 웹툰
- 공방: 8단계 카드 편집기, 칸마다 AI 초안, 3턴 테스트, 초상(파일 · AI)
- 월드코퍼챗: 세계관 편집기(인물 · 장소 · 파트 · 지도), 대화 방식 4가지(채팅 · 비주얼노벨 · 소설 · 메신저), 미니게임 창
- 글은 HTML로 넣지 않는다: lib/chat-format.ts가 표기를 읽고 React 요소로만 그린다(XSS 차단)

### 프론트엔드 — 이용자 웹 — API 연결
브라우저 → Next 서버 → Nest 순서만 허용한다. 브라우저에서 직접 부르는 길은 app/api/* 중계 라우트뿐이고, 여기에는 무거운 추론을 넣지 않는다.
- 읽기: 서버 컴포넌트 → lib/*.ts → GET Nest (Bearer)
- 쓰기: 클라이언트 → app/actions/*.ts(서버 액션) → POST Nest
- 대화 대기: app/api/characters/[id]/chat — 답을 기다리는 동안 대기 표시를 그리려고 쿠키 토큰을 붙여 넘긴다
- 그림: app/api/.../portrait · photonet · webtoon — <img>는 토큰을 못 붙여 서버가 받아 no-store로 돌려준다
- 이용자 IP: lib/client-ip.ts가 X-Forwarded-For + 프록시 토큰으로 넘긴다 → 요청 한도가 사람별로 센다

### 프론트엔드 — 이용자 웹 — 디자인
따뜻한 종이 · 구리 톤의 토큰 위에 라이트 · 다크 두 벌을 유지한다. 색 · 그림자 · 둥글기는 토큰만 쓰도록 규칙을 정해 테마가 깨지지 않게 했다. 대화는 말풍선 · 나레이션 · 행동 표기를 시각적으로 구분하고, 월드는 대화 방식마다 전혀 다른 레이아웃(무대 + 대사 상자, 문단, 메신저 말풍선)을 쓴다.

### 프론트엔드 — 이용자 웹 — 문제점과 개선

## 어드민 콘솔 — 운영자 웹

### 어드민 콘솔 — 운영자 웹 — 개요
신고 처리, 초상 · 그림 검수, 계정 정지와 등급 변경, 세계관 내리기와 이벤트 기록, 운영 설정을 한 곳에서 한다. 권한은 세 겹으로 확인한다.

- Nest AdminGuard: DB의 역할을 다시 확인
- 공개 호스트는 CONSOLE_IP_ALLOWLIST에 있는 IP만 연다

### 어드민 콘솔 — 운영자 웹 — 사용 엔진

- 인증: 콘솔 전용 쿠키, 운영자 계정만 로그인

## 백엔드 서버 — 유일한 신뢰 경계
Nest.js 12(ESM) + Prisma 7 + PostgreSQL 16. 외부에 열린 유일한 백엔드로 인증 · 권한 · 소유 확인 · 요청 한도 · 코레딧 · 맥락 조립을 모두 맡는다. 판단 로직은 순수 함수로 모아 DB 없이 시험한다.

### 백엔드 서버 — 유일한 신뢰 경계 — 개요
웹 · 콘솔은 Nest만 알고, Nest만 DB와 AI를 알고, AI는 DB를 모른다. 이 원칙 하나로 보안 검토와 시험 범위를 Nest 한 곳에 모았다. 모듈 30여 개, 2026-11-07에 대조한 API 경로 155개에 고객센터 문의 5경로를 더했다. 테이블 38개.
- Controller → Guard(Auth · Admin · RateLimit) → Service → 순수 함수 / Prisma / ai-client / Credits
- 운영 기동 검사: NODE_ENV=production에서 REQUIRE_HTTPS · 토큰 길이 · 개발 스위치를 보고 어긋나면 시작하지 않는다
- 운영: Oracle Cloud A1.Flex(ARM) Docker Compose — Caddy · api · postgres · ai · ollama

### 백엔드 서버 — 유일한 신뢰 경계 — 사용 엔진
- 런타임: Node.js 24 · Nest.js 12 (ESM)
- ORM · DB: Prisma 7 · PostgreSQL 16 · 마이그레이션 36개
- 메일: Nodemailer (SMTP · 폴더 · 로그)
- 결제: 토스페이먼츠 연동(보류) · 눌러서 프로(PRO_CLICK)
- 시험: Vitest 232개 — 순수 함수 *.spec.ts + 실제 PostgreSQL *.db.spec.ts

### 백엔드 서버 — 유일한 신뢰 경계 — 상세 기능
- character-chat: 대화 한 턴: 맥락 조립 → /infer → 개인사 검사 → 저장
- campaign-state: 뒤에서 정리: 메시지 6개마다 요약 · 기억 · 친밀도 · 복선 · 퀘스트 판정
- quests: 비밀 퀘스트: 건넴 → 달성 → 보상 장면 한 번
- worlds: 월드코퍼챗: 세계관 · 플레이 · 3턴마다 파트 판정 · 미니게임 · 하루 보상 한도
- studio: 공방: 초안 → 3턴 테스트 → 발행(이메일 인증 계정만)
- credits: 코레딧: 출석 · 차감 · 실패 환불 · 보상을 DB 한 문장으로
- persona-rag: 2-gram BM25 + 키워드 보너스 지식 조각 검색(벡터 DB 없음)

### 백엔드 서버 — 유일한 신뢰 경계 — API 연결
Nest 컨트롤러 경로 155개를 문서와 하나씩 대조해 빠진 것이 없음을 확인했다(2026-11-07). 2026-11-08에 고객센터 문의 5경로를 더했고, 전체를 다시 세지는 않았다. AI 호출은 대기열을 지나며, 화면에서 기다리는 답(foreground)이 뒤에서 하는 정리(background)보다 먼저 간다.
- POST /auth/signup · /auth/login: 가입 · 로그인 → 토큰(쿠키)
- POST /characters/:id/chat: 대화 한 턴 (답 · 사용량)
- POST /worlds/:id/play/turn: 월드 한 턴 (진행자 답 · 위치 · 이벤트)
- POST /studio/characters/:id/test: 발행 전 3턴 테스트
- GET /health: 상태 + AI 대기열(실행 · 대기 · 동시 수)

### 백엔드 서버 — 유일한 신뢰 경계 — 내부 구조

### 백엔드 서버 — 유일한 신뢰 경계 — 고급 기술
- 모델의 자기 확신을 믿지 않는다: 퀘스트 달성은 확신 ≥85, 인용 ≥8자, 인용이 그 화자의 실제 대사 안에 있을 때만 → 잘못 통과 0건
- 환각 억제: 설정에 없는 개인사를 묻는 턴만 /ground-check, 지어냈으면 다시 쓰기(최대 2번)
- AI 대기열: 동시 수 제한 + foreground 우선, 타임아웃 사슬(Vercel 300초 > API 280초 > 호스팅 45초)
- 돈과 횟수는 DB 한 문장(원자적 UPDATE)으로 세서 동시 요청에도 두 번 깎이지 않는다

## AI 서비스 — 연기 · 판정 · 그림
FastAPI(Python 3.12) 내부망 전용 서버. DB를 보지 않고 Nest가 조립해 넘긴 조각만 쓴다. 자체 가중치를 학습하지 않는 대신, 프롬프트 · 맥락 · 판정을 실제 모델로 재고 고쳤다.

### AI 서비스 — 연기 · 판정 · 그림 — 개요
연기(/infer), 요약 · 기억(/summarize · /remember), 환각 판정(/ground-check), 월드 진행자(/world/turn · /world/part-check), 그림(/photonet · /webtoon), 검수(/moderate-image) 등 경로 24개. 바깥에 열리지 않고 X-AI-Token이 맞는 요청만 받는다.
- 기본 무료는 gemma4:e4b를 로컬에서 그대로 쓴다
- 강화 무료는 키가 있으면 NVIDIA gemma-4-31b-it, 없으면 이 기기의 gemma4:12b
- 막히면 예비는 gemma4:e4b다. 없는 12b를 찾지 않는다
- 1:1 답은 웹소켓으로 토큰을 바로 보여 준다. 소켓은 글을 옮길 뿐 추론을 나누거나 빠르게 하지 않는다
- /train은 403 — v1은 학습하지 않는다는 정책

### AI 서비스 — 연기 · 판정 · 그림 — 사용 엔진
- 서버: FastAPI · Pydantic(camelCase 통신)
- 대화 모델: 기본 gemma4:e4b · 강화 gemma-4-31b-it · 예비 gemma4:e4b
- 그림: diffusers · Animagine XL 4.0 · SD 1.5 (NVIDIA GPU)

### AI 서비스 — 연기 · 판정 · 그림 — 상세 기능
