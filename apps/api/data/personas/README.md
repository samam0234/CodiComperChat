# 캐릭터 페르소나 지식 (RAG 원천)

챗봇이 자기 성격·배경·습관을 놓치거나 지어내지 않도록, 캐릭터별 설정을 **비공개 JSON**으로 두고
매 턴 이번 대화와 관련된 조각만 골라 모델에 넣는다. 이 폴더의 `*.json`은 git에 올라가지 않는다
(`_example.json`과 이 README만 추적). 카드 원문과 손으로 쓴 설정이 들어가기 때문이다.

## 만드는 법

```bash
# 1) 서버 DB의 공개 카드 필드로 시작 파일을 만든다 (비밀·해금 조건은 넣지 않는다)
npm run persona:build --workspace api            # 없는 캐릭터만 만든다
npm run persona:build --workspace api -- --force # 이미 있는 파일도 덮어쓴다 (손으로 고친 내용이 사라진다)

# 2) 만들어진 <캐릭터 이름>.json 을 열어 배경·관계·습관·말투 예시를 채운다

# 3) 이 캐릭터에서 어떤 조각이 검색되는지 확인한다
npm run persona:search --workspace api -- 유지성 "3년 전에 뭐 하셨어요?"
```

서버를 재시작할 필요 없이, 파일을 저장하면 몇 초 안에 반영된다.

## 형식 — `_example.json` 참고

| 필드 | 설명 |
|------|------|
| `schemaVersion` | 항상 `1` |
| `character` | `Character.name`과 **똑같이** 적는다. 이 이름으로 캐릭터에 붙는다 |
| `core` | 매 턴 **항상** 들어가는 극소 핵심(최대 8줄, 줄당 240자). 정체성·호칭·말투·금기. 길어지면 최근 대화가 밀려난다 |
| `chunks[].id` | 조각 식별자(중복 불가). 로그에 이것이 찍힌다 |
| `chunks[].type` | 자유 분류: `backstory` `relationship` `habit` `preference` `world` `speech_example` `boundary` … |
| `chunks[].topic` | 이 조각이 무엇에 관한지 짧은 제목(40자). 검색에서 본문보다 무겁게 본다 |
| `chunks[].keywords` | 선택(최대 30개). 동의어·별칭을 적는다. **이번 질문**에 그대로 들어 있으면 강하게 검색된다(직전 대화에서만 맞으면 약하게) |
| `chunks[].text` | 본문 1~3문장(500자 이하). 검색되면 이 글이 그대로 모델에 들어간다 |

## 잘 쓰는 요령

- **조각은 작게, 하나의 사실만.** 소설처럼 길게 쓰면 한 번에 다 들어가 최근 대화가 잘린다
- **설정에 없는 화제는 "없다"가 아니라 "설정에 없으니 단정하지 않는다"고 적어 둔다.** 캐릭터가 "형제는 없어요"처럼 없는 사실을 만들어 내지 않게, 예: "가족 이야기는 설정에 없다. 있다/없다로 단정하지 말고 말을 돌린다"
- **말투 예시(`speech_example`)를 몇 개 넣으면** 작은 모델일수록 말투가 훨씬 안정된다
- 비밀·해금 조건은 이 파일에 쓰지 않는다 (기획서 §7.8: 미해금 비밀은 서버 밖으로 나가지 않는다)

## 동작 방식

1. 유저 말 + 직전 두 턴으로 조각을 점수 매긴다 (한국어 글자 2-gram BM25 + 키워드 보너스)
2. 점수가 충분한 조각 최대 3개(본문 합 700자 이내)만 `activeLore`로 FastAPI에 넘긴다
3. 관련 조각이 하나도 없으면 아무것도 넣지 않는다 → 프롬프트의 "자료에 없는 사실은 지어내지 않는다" 규칙이 작동한다
4. 파일이 없거나 형식이 틀린 캐릭터는 예전 방식(카드 원문 전부)으로 대화한다. 서버 로그에 어디가 틀렸는지 남는다

끄려면 `apps/api/.env`에 `PERSONA_RAG=off`.
