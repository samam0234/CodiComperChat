3-4 보충: "Select existing virtual cloud network"를 골랐는데 VCN이 없을 때

이 보충 화면은 앞의 화면들보다 확인이 덜 됐습니다. 이번 보충은 공식 문서를 다시 열어 보지 못하고 알려진 콘솔 흐름(VCN 마법사, VCN 상세 탭)을 기억으로 그렸습니다. 그래서 문구가 거의 다 추정입니다(점선 밑줄). 가장 쉬운 길은 길 A(마법사)이고, 길 B는 하나씩 직접 만드는 방법입니다. 길 A로 되면 길 B는 읽지 않아도 됩니다.

인스턴스 만들기 화면의 Networking에서 Select existing virtual cloud network를 고르면, 같은 구획(compartment)에 VCN이 이미 있어야 목록에 나옵니다. 새 계정은 VCN이 없어서 목록이 비어 있습니다. 가장 간단한 해결은 위 3-4에서 Create new virtual cloud network를 고르는 것이고(그러면 아래 과정이 자동으로 됩니다), 굳이 기존 것을 고르려면 인스턴스 만들기 창을 닫지 말고 새 탭에서 콘솔을 열어 VCN을 먼저 만듭니다.

  3. 부트 볼륨 크기를 100GB로 늘립니다(기본은 약 50GB). 칸 이름은 추정이고, 문서에는 "Boot volume 설정을 확인하고 Use in-transit encryption을 선택"이라고만 있습니다.

Out of host capacity for shape VM.Standard.A1.Flex in availability domain …

  • 3-1의 Availability domain을 다른 것으로 바꿔 다시 Create를 누릅니다.
  • 시간을 두고(새벽 등) 다시 시도합니다. 무료 ARM은 자리가 자주 모자랍니다.
  • 홈 리전이 붐비면 다른 리전은 못 쓰니(홈 리전 고정), 정 안 되면 Pay As You Go로 계정을 올리면 자리를 얻기 쉽다는 후기가 있습니다. 후기 기준, Oracle 공식 확인 아님 무료 한도 안에서는 청구되지 않지만, 한도를 넘는 자원을 만들면 청구됩니다.
  • 7일간 CPU·네트워크·메모리가 모두 20% 미만이면 회수될 수 있다는 Oracle 규칙이 있습니다. 서버가 한가하면 위험하니 백업을 VM 밖에도 둡니다.
