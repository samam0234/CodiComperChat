AI 서버 배포 실행 안내

명령 한 줄로 Oracle VM에 AI 서버를 올린다 · 2026-11-07

시작 전 확인실행화면 예시키 입력실패했을 때끝난 뒤Code 창에 맡기기
한 줄 요약. 터미널에 아래 4줄을 붙여 넣고, 중간에 NVIDIA 키를 한 번 붙여 넣으면 된다. 코드 올리기, 스왑, 컨테이너 빌드, 예비 모델 받기, 동작 확인까지 스크립트가 알아서 한다. 5~15분 걸리고, 여러 번 실행해도 안전하다(이미 된 건 건너뛴다).

시작 전 확인 (1분)

PowerShell을 열고 아래 두 줄이 예시와 비슷하게 나오는지 본다.

node -v
ssh codicomper-oci "echo 접속됨"

실행 PowerShell

지금 작업 중인 폴더를 건드리지 않도록 별도 폴더(D:\vscode\ccc-ai-deploy)에 main 코드를 꺼낸다. 아래를 한 번에 붙여 넣는다.

cd D:\vscode\CodiComperChat
git fetch origin main
git worktree add ../ccc-ai-deploy origin/main
cd ../ccc-ai-deploy
node scripts/deploy-ai-oracle.mjs
  • git worktree add는 같은 저장소의 다른 폴더를 만든다. 지금 하던 브랜치·수정 중인 파일은 그대로다.
  • 스크립트가 하는 일: ① 최신 코드 가져오기 ② 서버로 업로드(서버의 .env는 안 덮어씀) ③ 서버에서 ai-deploy.sh 실행.
  • 다시 실행할 때(키만 바꾸거나 실패 후 재시도): cd D:\vscode\ccc-ai-deploy 후 마지막 줄만 다시 입력한다.
  • 폴더가 이미 있다는 오류가 나면 git worktree add 줄은 건너뛰고 나머지만 실행한다.

키 입력 화면 [2/6]

  NVIDIA 키(nvapi-로 시작)를 붙여 넣고 Enter (화면에 안 보임): _
  1. 준비해 둔 nvapi-… 키를 우클릭(또는 Ctrl+V)으로 붙여 넣고 Enter. 글자가 하나도 안 보이는 것이 정상이다.
  2. 키 앞뒤 공백은 자동으로 지워진다.
  3. 키는 서버의 deploy/oracle/.env에만 저장된다. 이 PC·채팅·로그 어디에도 남지 않는다.
  4. 서버에 이미 키가 있으면 이 단계는 묻지 않고 지나간다.
키를 채팅이나 Code 창에 붙여 넣지 않는다. 실수로 붙여 넣었다면 build.nvidia.com에서 그 키를 폐기하고 새로 만든다.

실패했을 때 화면과 대처

1) 키가 거절됨

  ✗ NVIDIA가 키를 거절했다(HTTP 401). build.nvidia.com에서 키를 새로 만들어 붙여 넣는다 (1/3)

바로 아래에서 다시 입력하게 한다(최대 3번). 키를 통째로 다시 복사해서 붙여 넣는다. 계속 안 되면 키를 새로 만든다.

2) 모델 이름이 다름

  ! NVIDIA 모델 목록에 Gemma 4 31B가 없다. 이름이 바뀌었을 수 있다.
      gemma 계열: google/gemma-3-27b-it, google/gemma-4-26b-a4b-it
  ✗ 모델 google/gemma-4-31b-it 을 NVIDIA에서 찾지 못했다(HTTP 404). 위 gemma 목록을 보고 .env의 LLM_API_MODEL을 고친다.

이 화면 전체를 복사해서 이 스레드(또는 Code 창)에 붙여 넣는다. 목록 중 쓸 모델을 정해 설정을 고쳐 준다. 직접 하려면 서버에서 LLM_API_MODEL=목록의_이름으로 바꾼 뒤 다시 실행한다.

3) 일부 실패

  ✗ ai가 healthy가 되지 않았다 (상태: starting)
      ...(ai 컨테이너 로그 15줄)...

== 일부 실패: ai 컨테이너 ==
위 ✗ 줄과 로그를 그대로 알려 준다. (되돌리기: docker compose ... stop ai ollama)

화면 전체를 복사해서 알려 주면 원인을 찾는다. 사이트가 급하면 되돌릴 수 있다: AI만 내려도 API·DB는 그대로 돈다.

4) 서버 접속 자체가 안 됨

  ✗ 서버에 접속하지 못했다. 'ssh codicomper-oci' 가 되는지 확인한다.

시작 전 확인의 두 번째 줄부터 다시 본다.

끝난 뒤 체크

임시 폴더 정리(선택): cd D:\vscode\CodiComperChat 후 git worktree remove ../ccc-ai-deploy

Code 창(Claude Code)에 맡기기 선택

키만은 직접 넣어야 한다(채팅에 안 남기려고). 두 번에 나눈다.

1) PowerShell에서 키만 넣는다 (위 실행 4줄과 같되 마지막 줄만 다르다)

cd D:\vscode\CodiComperChat
git fetch origin main
git worktree add ../ccc-ai-deploy origin/main
cd ../ccc-ai-deploy
node scripts/deploy-ai-oracle.mjs --key-only

키를 붙여 넣고 ✓ 키 확인됨, 키 설정 끝이 나오면 된다.

2) Code 창에 붙여 넣는다

docs/web_management/ai-deploy-handover.md 를 git show origin/main:docs/web_management/ai-deploy-handover.md 로 읽고 그대로 진행해 줘.
키는 이미 서버에 넣어 뒀으니 묻거나 출력하지 마. 병합과 푸시는 하지 마.

Code 창은 같은 스크립트를 실행하고, 화면에 나온 ✓/✗를 요약해 알려 준다.
