키 안전수칙 꼭 읽기

키를 채팅·Code 창·메모·스크린샷에 붙여 넣지 않는다. 붙여 넣은 순간 기록에 남는다. 키는 서버의 deploy/oracle/.env 한 곳에만 둔다(이 파일은 git에 올라가지 않는다).
  • 이미 어딘가에 붙여 넣었다면 build.nvidia.com에서 그 키를 지우고(Revoke) 새로 만든 뒤 1단계를 다시 한다.
  • 키 유효기간은 약 6개월이다(3rd-party 자료 기준). 만료되면 대화가 401 오류를 내거나 예비(CPU)로만 답한다. 1단계를 다시 하면 된다.
  • 무료 키는 분당 약 40회가 공개된 한도다. 상업 이용 조건은 분명하지 않으니 정식 오픈 전에 NVIDIA 약관을 확인한다.

1서버에 키 넣기 내 PC 터미널 → 서버

가) 서버에 접속한다. PowerShell(또는 터미널)에서:

ssh codicomper-oci

화면이 ubuntu@…:~$처럼 바뀌면 서버 안이다. (처음 접속이면 yes를 입력한다.)

나) 아래 상자를 통째로 붙여 넣는다. 키를 물으면 nvapi-… 키를 붙여 넣고 Enter. 화면에 아무것도 안 보이는 것이 정상이다.

cd ~/codicomperchat
read -rsp "NVIDIA 키: " K; echo
E=deploy/oracle/.env
sudo sed -i '/^LLM_BACKEND=/d;/^LLM_API_KEY=/d;/^AI_CONCURRENCY=/d;/^OLLAMA_MODEL=/d' $E
printf '\nLLM_BACKEND=openai\nLLM_API_KEY=%s\nAI_CONCURRENCY=2\nOLLAMA_MODEL=gemma4:e4b\n' "$K" | sudo tee -a $E >/dev/null
unset K
sudo grep -c '^LLM_API_KEY=nvapi-' $E

각 줄이 하는 일

  1. cd …: 서버의 프로젝트 폴더로 간다. 백엔드를 올렸을 때 이미 만들어져 있다.
  2. read -rsp: 키를 입력받는다. -s 때문에 화면에 안 찍히고 명령 기록에도 값이 남지 않는다. K라는 임시 변수에만 담긴다.
  3. sed -i '/…/d': .env에 같은 이름의 옛 줄이 있으면 지운다. 여러 번 실행해도 줄이 중복되지 않는다.
  4. printf … | sudo tee -a: 네 줄을 .env 맨 아래에 붙인다. 뜻은 LLM_BACKEND=openai(NVIDIA API로 대화), LLM_API_KEY(키), AI_CONCURRENCY=2(동시 2요청), OLLAMA_MODEL(예비 모델).
  5. unset K: 임시 변수를 지운다.
  6. grep -c: nvapi-로 시작하는 키 줄이 몇 개인지 센다.
성공 기준: 마지막 줄에 1이 찍힌다. 0이면 키 입력이 비었거나 붙여 넣기가 잘못된 것이다. 같은 상자를 다시 붙여 넣는다.

다) 서버에서 나온다. exit 입력 후 Enter. 그다음 "키 넣었어"라고 Code 창에 알린다(2단계 문장에 포함돼 있다).

2Code 창에 붙여 넣기 Claude Code

저장소 D:\vscode\CodiComperChat를 연 Code 창(Claude Code)에서 아래 문장을 그대로 붙여 넣는다.

git fetch origin claude/project-thread-pz0x5f 를 한 다음, git show origin/claude/project-thread-pz0x5f:docs/web_management/ai-deploy-handover.md 를 읽고 그 문서대로 Oracle VM에 AI 서버를 배포해 줘.
NVIDIA API 키는 내가 이미 서버 .env에 넣어 뒀어. 키를 나한테 묻거나 출력하지 마.
작업 브랜치는 바꾸지 말고, 병합과 푸시는 하지 마. 끝나면 확인 결과만 짧게 알려 줘.
  • PR #3 브랜치는 아직 병합 전이라 내 PC의 현재 브랜치에는 이 문서가 없다. 그래서 git fetch로 가져와 git show로 읽게 한다.
  • "작업 브랜치는 바꾸지 말고"가 중요하다. 지금 하던 작업이 있어도 건드리지 않고 원격 브랜치를 그대로 서버로 보낸다.
  • Code 창이 파일을 못 읽으면 프로젝트 파일에 올려 둔 deploy/ai-deploy-handover.md의 내용을 그대로 붙여 넣어도 된다.
