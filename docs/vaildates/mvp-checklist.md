# v1 MVP 체크리스트

정본: `CodiComperChat_project_plan.md` §9.1, §14. 데모/배포 전에 이 항목들을 통과했는지 확인한다.

## v1이 증명해야 하는 것 (§9.1)

- [ ] 세션을 넘기면 캐릭터가 지난 훅을 먼저 꺼낸다
- [ ] 비밀이 조건 전에 새지 않는다
- [ ] 말투가 20턴 근처까지 버틴다
- [ ] 유저가 "채팅방"이 아니라 "회차"로 기억한다

## 플레이테스트 시트 (§14, 기능 체크리스트가 아니라 제품 체크리스트)

- [ ] 1. 첫 화면만 보고 "캐릭터챗" 외에 무엇이 다른지 한 문장으로 말할 수 있는가
- [ ] 2. 첫 5턴 안에 비서가 아니라 인물이 보이는가
- [ ] 3. 세션을 닫고 다시 열었을 때, 캐릭터가 시스템 로그가 아니라 자기 입으로 지난 일을 꺼내는가
- [ ] 4. 아직 잠긴 비밀을 유저가 유도해도 먼저 털지 않는가
- [ ] 5. 같은 질문 `"지금 뭐 해?"`를 공방 샘플과 실제 세션에서 비교해도 말투가 같은가
- [ ] 6. 관계 숫자를 숨겨도 대사만으로 관계가 변한 느낌이 나는가
- [ ] 7. 로어를 많이 넣은 카드에서 최근 장면이 흐려지지 않는가
- [ ] 8. FastAPI가 죽어도 Nest가 유저 메시지를 잃지 않는가 (적어도 저장)
- [ ] 9. 공방에서 갈등과 비밀이 비어 있으면 발행이 막히거나 강하게 경고되는가
- [ ] 10. 팀이 "학습이 없어서 차별점이 없다"고 느끼는가 — 느낀다면 상태 UI가 약하거나 카드가 약한 것. 모델 탓으로 가지 말 것

## v1 범위 밖 (§9.2, 체크리스트에 넣지 않는다)

유저 캐릭터 광장/카드 마켓, 자체 LLM 학습, 멀티플레이/파티 채팅, 음성 통화·만화 자동생성, 생산성 기능, 복잡한 전투 룰북 — 이 항목들이 안 되는 것은 결함이 아니다.
