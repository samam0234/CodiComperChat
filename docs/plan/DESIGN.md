# 웹 디자인 규칙

콘셉트: **"밤하늘 아래 이어지는 이야기"** — 보랏빛 밤(주색)과 분홍빛 별(보조색), 은은한 오로라 배경, 말풍선 로고. 캐릭터와의 대화가 주인공이라 화면은 차분하게 두고, 캐릭터(초상·말풍선)와 주요 버튼에만 빛을 준다.

## 토큰 (`apps/web/app/globals.css`)

화면 CSS는 색·그림자·둥글기를 직접 쓰지 않고 아래 이름만 쓴다. 라이트·다크는 같은 이름에 다른 값이 들어간다. 어느 쪽을 보일지는 서버가 `data-theme`으로 늘 정해 보낸다 — 기본은 한국 시각 오전 7시~오후 10시 밝게·그 밖에 어둡게(시간표), 설정에서 밝기·다크 영구 설정, 헤더의 해·달 버튼으로 다음 전환까지 잠깐 바꾸기 (`apps/web/lib/theme-schedule.ts`).

| 이름 | 쓰임 |
|---|---|
| `--background` | 페이지 바탕, 카드 안쪽의 움푹한 칸(입력창) |
| `--surface` / `--surface-2` | 떠 있는 카드 / 옅은 칸·눌린 상태 |
| `--foreground` / `--muted` | 본문 / 보조 글 |
| `--border` | 테두리 |
| `--accent` / `--accent-soft` | 주색(링크·강조) / 옅은 주색 배경(칩·선택) |
| `--pink` / `--pink-soft` | 보조색 |
| `--gradient` | 주요 버튼·내 말풍선·로고·공식 배지 |
| `--shadow-sm/md/lg`, `--glow` | 카드 그림자 / 주요 버튼 빛 |
| `--glass` | 헤더·메뉴 버튼의 반투명 유리 |
| `--danger` / `--success` | 오류 / 완료 |

## 모양

- 주요 버튼: 알약형(`border-radius: 999px`) + `--gradient` + `--glow`. 보조 버튼: 알약형 + 테두리.
- 카드 둥글기: 작은 카드 16~20px, 큰 영역(히어로·채팅창·로그인 상자) 24~32px.
- 말풍선: 캐릭터는 왼쪽(초상 + 흰 말풍선, 왼쪽 아래 모서리만 뾰족), 나는 오른쪽(그라데이션, 오른쪽 아래 모서리만 뾰족).
- 캐릭터 카드: 초상을 크게(4:4.4), 아래쪽을 어둡게 해 이름을 그림 위에 둔다. 초상이 없으면 이름으로 정한 색(`nameHue`)의 그라데이션 위에 첫 글자.
- 한국어는 낱말 가운데서 줄을 바꾸지 않는다(`word-break: keep-all`).
- 움직임은 짧게(0.18~0.35초). `prefers-reduced-motion`이면 끈다.
