## 기획서 §8 화면 지도와의 관계

`CodiComperChat_project_plan.md` §8의 화면 지도(홈 / 세션 / 캠페인 상태 패널 / 캐릭터 공방 / 세션 로그북 / 설정)와 이 IA는 다음처럼 대응한다. **원본은 수정하지 않았다** (§0 원본 보존 원칙).

| 이번 IA | 기획서 §8 | 비고 |
|---------|-----------|------|
| 홈 | 홈 | 동일 |
| 대화 목록 (라이브러리) | 세션 로그북 + 진행 중 캠페인 | 라벨만 다름 |
| 제작 | 캐릭터 공방 | API는 `/studio/*` (기획서 §13.1)와 일치 |
| 설정 | 설정 | 동일 |
| 인기 | (없음) | 신규 |
| 에이전트 | (없음) | 신규. 캐릭터 탐색 진입점 |
| 마이페이지 | (없음) | 신규 |
| 세션(채팅), 캠페인 상태 패널 | 있음 | 이번 셸에는 아직 없음 — 기획서 §10의 4번 단계에서 추가 |

**용어 주의:** 기획서의 이름 구분 표에 따르면 플랫폼은 `코디컴퍼챗`, AI 기능은 `캠페니언(AI Companion)`이다. 헤더 라벨 `에이전트`는 기획서 어휘에 없는 신규 사용자 노출 용어다(기획서에서는 §7.6의 "캐릭터 에이전트"라는 내부 용어로만 등장). 정식 계획서를 갱신할 때 이 라벨을 확정하거나 `캠페니언`/`캐릭터`로 정렬할지 결정이 필요하다.
