# 캐릭터 공방 (Studio) 가이드

정본: `CodiComperChat_project_plan.md` §6. 상태: **UI 미구현 — v1에서 `apps/web` 안 운영자 전용 화면으로 예정** (`../Architecture/apps.md` 참고, 별도 앱 아님).

## 레이아웃 (계획서 §6.1)

왼쪽 단계 / 가운데 폼 / 오른쪽 라이브 프리뷰.

```text
캐릭터 공방                    초안저장    미리보기    발행

STEP          현재 단계 폼                 라이브 프리뷰
1 정체성                                   초상 / 이름 / 한줄
2 외형                                     태그 / 토큰 예상
3 성격·말투
4 캠페인 역할                              [테스트 대화 3턴]
5 비밀·경계
6 첫인사
7 로어북
```

- 초안 저장은 언제든
- 발행은 필수 단계(3, 4, 6)와 테스트 통과 후
- 단계마다 "이 칸만 AI로 초안" 버튼. 전체 자동생성은 기본값으로 두지 않는다

## 7단계 필드 의도 (계획서 §6.2, 요약)

| 단계 | 핵심 |
|------|------|
| 1 정체성 | 목록에 나가는 얼굴. 한 줄 소개 40자 제한 |
| 2 외형 | 흉상 초상 우선, 전신 일러스트는 v1 범위 밖 |
| 3 성격·말투 | 긴 설명 한 칸 금지 — 축 + 규칙 + 습관으로 쪼갬. 같은 질문 샘플 답 2개로 검증 |
| 4 캠페인 역할 | 일반 캐릭터챗에 없는 칸. 없으면 캠페니언이 아니라 그냥 캐릭터챗 |
| 5 비밀·경계 | 비밀은 항상 해금 조건과 쌍 |
| 6 첫인사·예시 | 상황 2~4줄 + 대사 1~2줄. 예시 대화는 짧은 페어 2개면 충분 |
| 7 로어북 | 템플릿 3개(세계 규칙/인물/금기)만 열고 나머지는 접음 |

## UX 장치 (계획서 §6.3)

- 글자 수 대신 **토큰 예상치**를 오른쪽에 표시
- 비밀과 갈등 씨앗이 둘 다 비면 "캠페인 밀도 부족" 경고
- 테스트 3턴에서 설명충/캐릭터 붕괴가 보이면 발행 차단/경고
- 모바일은 프리뷰를 하단 시트로
