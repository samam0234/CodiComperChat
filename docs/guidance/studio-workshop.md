# 캐릭터 공방 (Studio) 가이드

정본: `CodiComperChat_project_plan.md` §6. 최종 갱신 2026-10-24 — **구현됨** (`/studio`, `/studio/:id`, `apps/web` 안의 화면). 계획서는 v1 운영자 전용이었으나 사용자 지시로 **일반 유저도** 만들고 발행한다.

## 레이아웃 (계획서 §6.1)

왼쪽 단계 / 가운데 폼 / 오른쪽 라이브 프리뷰 — 계획서 그대로.

```text
← 공방  이름         저장됨  초안 저장  [공개 범위 ▾]  발행

STEP           현재 단계 폼                   프리뷰
1 정체성 필수                                  이름 / 한 줄 / 태그 / 항상 들어가는 설정 약 N 토큰
2 외형         (흉상 초상 올리기·검수 상태)     발행 준비: 필수 단계 · 테스트 3턴 · 공개 범위
3 성격·말투 필수                               테스트 대화 3턴 + 판정 결과
4 캠페인 역할 필수
5 비밀·경계
6 첫인사 필수
7 로어북
8 비밀 퀘스트 (선택)
```

- 초안은 입력을 멈추면 자동 저장(0.8초), "초안 저장"으로도
- 칸마다 **AI 초안** 버튼: 제안만 보여 주고 고르면 들어간다(카드는 안 바뀜). 비밀·이름·예시 대화는 AI에 보내지 않는다
- 성격·말투 단계의 **샘플 답**: 같은 질문에 대한 답 2개로 말투를 미리 본다

## 비밀 퀘스트 (8단계, 선택 — 2026-10-24)

캐릭터가 친해진 유저에게 먼저 건네는 숨은 부탁. 구조·진행·보상은 [../plan/SECRET_QUEST.md](../plan/SECRET_QUEST.md).

- 칸: 퀘스트 이름(30자) · 퀘스트 부탁 · 달성 조건 · 보상 장면(선택) · 열리는 친밀도(슬라이더). 이름·부탁·달성 조건은 쌍이다 — 하나라도 쓰면 셋 다 필요하고, 덜 쓴 퀘스트는 발행해도 붙지 않는다
- **직접 쓰기**, 칸별 **AI 초안**(기존과 같은 방식), 또는 **"AI로 퀘스트 만들기"**: 카드 설정(비밀·해금 조건 제외)을 읽고 한 번에 4칸+친밀도를 제안 → "적용하기"를 눌러야 들어가고, 적용한 뒤 칸마다 고칠 수 있다. "퀘스트 지우기"로 비운다
- 달성 조건은 **대화 기록만 보고 예/아니오로 판정할 수 있게** 눈에 보이는 행동·말로 쓴다("유저가 문제를 같이 풀어 보겠다고 말한다"). 한 번의 대화 흐름에서 이룰 수 있는 크기가 좋다. 캐릭터(모델)에게는 알려지지 않는다
- 퀘스트는 3턴 테스트에 쓰이지 않아 고쳐도 테스트가 무효가 되지 않는다. 유저가 만든 캐릭터의 퀘스트는 보상 장면만 있고 코레딧은 없다(공식 캐릭터만 100 코레딧)

## 발행 조건

1. **이메일 인증**한 계정
2. 필수 단계(1·3·4·6) 채움
3. **지금 카드로** 3턴 테스트 통과 — 판정: 말투·성격 붕괴, 설명충(강의식 답), 메타 발언(AI·설정 언급), 비밀 누설, 설정에 없는 개인사 지어냄. 통과 뒤 카드를 고치면 "이전 테스트가 무효" → 다시 테스트
4. 운영자가 내린 캐릭터가 아님(내려간 캐릭터는 주인이 다시 올릴 수 없다)

공개 범위: **공개**(홈·인기 목록), **링크 공개**(주소를 아는 사람만), **비공개**(나만). 발행 뒤에도 바꿀 수 있고 다시 테스트할 필요 없다.

## 초상 (2단계)

두 가지 방법이 있다: **내 파일 선택**(올리기) / **AI로 직접 만들기**(2026-10-25, 한 장 25 코레딧).

- AI로 직접 만들기: 화풍 4가지(애니메이션·웹툰·수채화·실사풍) 중 하나와 생김새(성별·나이대 20대~·머리색·머리 모양·눈 색·옷차림·표정·배경)를 고르고, 추가 설명(100자)을 적을 수 있다. "카드의 외형 서술·분위기 키워드도 반영하기"를 켜 두면 카드 외형 서술을 로컬 LLM이 영어 태그로 옮겨 함께 그린다
- 모든 인물은 성인으로, 전체 이용가로만 그린다(남에게 보이는 초상이라 성인 모드 없음). 그림 검수(전체 이용가 규칙)를 거친 뒤 **올린 그림과 같은 초상 자동 검수**로 저장된다. 못 만들거나 검수에서 막히면 코레딧을 돌려준다. 실사풍은 실제 사진처럼 보여 운영자 확인(PENDING)으로 갈 수 있다
- 한 장 1분 안팎(화풍 계열을 바꾼 첫 장은 더). 요청 한도 10분 6장. 그림 엔진이 꺼져 있으면 503(코레딧 안 뺌)

- 그림을 고르면 브라우저가 정사각형으로 잘라 줄인다(webp/jpeg, 150KB 이하). 서버가 형식·크기를 다시 검사한다
- 올리면 **자동 검수**: 통과 → 바로 보임 / 애매함 → "운영자 확인 중"(그동안 남에게 초상 없이 보임) / 명백히 안 됨 → 올라가지 않음. 반려되면 사유가 보인다
- 초상은 카드와 따로라 바꿔도 다시 테스트할 필요 없다

## 글자 수와 프로 등급

- 칸마다 글자 수 상한. 프로 등급은 **긴 글 칸**(외형 서술·성격 요약·캠페인 역할 6칸·첫 메시지·로어)만 3배이고, 매 턴 들어가는 짧은 칸(이름·호칭 규칙·말투 습관 등)은 그대로다(계획서 §6.3 컨텍스트 예산)
- 무료에서 긴 글 칸의 "프롬프트 연장"을 누르면 요금 안내로 이어진다. 프로가 끝나도 이미 쓴 긴 글은 남고, 늘리는 것만 막힌다

## UX 장치 (계획서 §6.3 → 지금)

| 계획서 | 지금 |
|--------|------|
| 글자 수 대신 토큰 예상치 | 프리뷰에 "항상 들어가는 설정 약 N 토큰" + 칸마다 글자 수 |
| 비밀·갈등 씨앗이 둘 다 비면 경고 | 프리뷰 "발행 준비"에 "캠페인 밀도 부족" 경고(서버 `readiness`가 계산) |
| 테스트 3턴에서 붕괴가 보이면 발행 차단 | 판정 통과해야 발행 버튼이 열린다 |
| 모바일은 프리뷰를 하단 시트로 | 좁은 화면(900px 이하)에서는 한 줄로 쌓고, 위쪽 "미리보기 / 폼 보기" 버튼으로 프리뷰와 폼을 바꿔 본다 |
