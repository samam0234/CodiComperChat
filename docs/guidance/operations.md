# 운영 가이드 (운영자)

운영자(`role=ADMIN`)가 하는 일과 도구. 최종 갱신 2026-10-24. 화면은 **운영 콘솔**(`console/`, 개발 `http://localhost:3001`, `npm run dev:console`)에 있다. 이용자 사이트 마이페이지의 "운영 콘솔 열기"로도 간다. 콘솔에는 따로 로그인한다(운영자 계정만).

## 전제

| 항목 | 방법 |
|------|------|
| 운영자 만들기 | 가입 후 `npm run user:role --workspace api -- 이메일 admin` (되돌리기 `user`) |
| 권한 확인 | 화면은 숨기기만 하고, 진짜 확인은 Nest `AdminGuard`가 매 요청 DB의 역할로 한다 — 역할을 바꾸면 바로 적용 |

## 대시보드 (`/`)

처리할 일(열린 신고·초상 검수 대기·내려간 캐릭터)이 맨 위. 빨간 숫자부터 처리한다. 아래에 이용자·캐릭터·대화 숫자와 AI 호출 대기열(이 API 서버 기준)이 있다.

## 신고 처리 (`/reports`)

1. 신고가 많은 캐릭터가 위에 나온다. 신고 사유·내용·신고한 사람이 보인다
2. **캐릭터 내리기**: 사유 필수 → 목록·상세·대화 어디에도 안 나오고, 만든 사람은 공방에서 사유를 본다. 주인은 다시 발행할 수 없다
3. **신고 기각**: 처리 메모를 남기고 닫는다
4. **복구**: 내린 캐릭터를 다시 보이게

## 초상 검수 (`/portraits`)

자동 검수가 확신하지 못했거나(실존 인물 사진·혐오 상징 가능성 등) 자동 검수를 하지 못한(AI가 꺼짐) 초상만 온다. 그동안 그 캐릭터는 남에게 초상 없이 보인다.

- **승인** → 발행된 캐릭터에 바로 실린다
- **반려**(사유 필수) → 만든 사람이 공방 외형 단계에서 사유를 본다. 새 그림을 올리면 다시 검수

## 캐릭터 관리 (`/characters`)

모든 캐릭터(비공개·링크 공개·내려간 것·발행 취소까지). 이름·한 줄 소개로 찾고 상태로 거른다. 신고가 없어도 **내리기**(사유 필수) / **복구**를 바로 할 수 있다. 이름을 누르면 이용자 사이트의 실제 화면이 새 탭으로 열린다.

## 계정 등급과 환불 (`/users`)

1. 이메일로 계정을 찾는다 → 지금 등급·만료일·결제 내역
2. **프로로**(일수, 비우면 만료 없음) / **무료로** — 보상·시험 계정용. 결제 기록은 바뀌지 않는다
3. **환불**: 결제 옆 "환불" + 사유 → 토스에 취소를 요청하고, **성공해야** 기록을 환불됨으로 바꾸고 그 결제의 일수만큼 프로 기간을 줄인다. 실패하면 결제사의 사유가 보이고 아무것도 바뀌지 않는다
   - 환불 기준(7일·미사용 전액 등)은 이용약관을 따른다. 사용 후 환불 기준은 법률 검토 후 확정 예정

스크립트로도 등급을 바꿀 수 있다: `npm run user:plan --workspace api -- 이메일 pro 30`

## 그림 엔진 운영 (코디포토넷·웹툰)

- 켜기·끄기·확인: [photonet-engine.md](photonet-engine.md). 기본(`IMAGE_ENGINE=local`)은 services/ai가 GPU에서 직접 그리므로 따로 켤 것이 없다 — AI 서비스 로그에 모델 읽기가 보이고, 코디포토넷 창이 "준비 중"이면 설치(`requirements-image.txt`)나 모델 파일(`services/ai/models/`)을 확인한다
- 한 장 약 35~60초(첫 모델 읽기는 수 분). 그림은 한 번에 하나씩 그려서 동시 요청은 줄을 선다. 요청 한도: 코디포토넷 10분 6장, 웹툰 콘티 10분 6번·컷 10분 14컷
- **그래픽 메모리**: Ollama와 나눠 쓴다. 그림 직전에 LLM을 내리고(`keep_alive 0`), 모자라면 `SD_OFFLOAD=1`
- 로그: 그림 검수가 막으면 AI 서비스 로그에 `photonet 검수에서 막음 rating=… flags=[…]`(그림 내용은 남기지 않는다). 성인 모드에서 `young`·`realistic`이 자주 보이면 모델·프롬프트를 점검한다

## 성인 콘텐츠 (현재 상태)

- 성인 모드는 이용자가 성인 확인(생년월일+동의+이메일 인증)을 해야 쓴다. **운영자가 성인 그림을 볼 수 있는 화면은 없다** — 신고·검토·접근 차단 운영 체계는 아직 없다(사용자 결정 대기)
- 계정이 거짓 정보를 입력했음을 알게 되면 이용약관에 따라 계정을 정지할 수 있다(현재 도구: 계정 등급·캐릭터 내리기뿐, 계정 정지 기능은 없다)
- 공개 전에 정해야 할 것: [../../SECURITY.md](../../SECURITY.md) "공개 전 필수"

## 코레딧·퀘스트 점검

- 코레딧 기록: 마이페이지 "코레딧"(이용자), DB `credit_ledger`(이유 ATTENDANCE·MODEL_USE·REFUND·ADMIN·OPERATION·QUEST). 그림·웹툰·오퍼레이션이 실패하면 REFUND가 한 줄 남는다
- 비밀 퀘스트: 공식 캐릭터는 `prisma db seed`가 유지성 퀘스트를 맞춘다(이미 있어도). 달성 로그는 api 로그의 `비밀 퀘스트 달성 character=… reward=…`. 보상은 계정×캐릭터당 한 번(`quest_rewards`)

## 점검 도구

| 무엇 | 명령·위치 | 결과 |
|------|-----------|------|
| 서버·AI 대기열 상태 | `GET /health` | `ai.inFlight`·`waitingForeground`가 계속 높으면 모델이 밀린다(`AI_CONCURRENCY`·모델 서버 확인) |
| 토스 키·연결 | `npm run billing:check --workspace api` | `✓ … 인증·연결 정상` (돈은 오가지 않음) |
| 메일 발송 | `npm run mail:check --workspace api -- 받을주소` | 시험 메일 한 통 |
| CSP 위반 | 웹 서버 로그의 `[CSP 위반] 지시어 막음: 주소 · 화면: 주소` | 새 외부 자원을 붙였는데 `apps/web/proxy.ts`의 CSP에 출처를 안 더했을 때 보인다 |
| 메일 실패 | api 로그의 `메일 발송 실패` / `메일 발송 설정(MAIL_SMTP_URL)이 없어` | |
| 요청 한도 저장소 오류 | api 로그의 `요청 한도 확인 실패 → 통과` | DB 저장소가 잠깐 실패해 막지 않고 통과시킨 것 |
| 페르소나 지식 | `npm run persona:build --workspace api`, `npm run persona:search --workspace api -- 이름 "질문"` | [`apps/api/data/personas/README.md`](../../apps/api/data/personas/README.md) |

## 회원 탈퇴 요청이 왔을 때

이용자가 설정에서 직접 탈퇴할 수 있다. 결제 기록은 계정 연결만 끊고 구매자 이메일과 함께 남는다(법정 보관) — 탈퇴 뒤에도 환불은 콘솔 `/users`에서 할 수 없으므로(계정이 없어 찾을 수 없음) 결제사 관리 화면에서 처리한다.
