# 웹(유저 프론트) 가이드

정본: `CodiComperChat_project_plan.md` §5. 상태: **UI 미구현.**

## 첫 방문 (계획서 §5.1)

1. 짧은 세계관 한 화면 (기능 나열 금지, 한 캐릭터의 눈과 한 줄)
2. 캐릭터 1~3 중 선택
3. 내 주인공 호칭만 정해도 시작 가능
4. 첫인사 = 시작 장면
5. 3~5턴 안에 "이 사람은 도우미가 아니다"가 느껴져야 함

온보딩에서 설정 폼을 많이 받지 않는다 — 설정은 캠페인이 열린 뒤 스며들게 한다.

## 일상 방문 (계획서 §5.2)

1. 진행 중 캠페인 카드가 홈 맨 위
2. "지난 세션에서 남은 것" 한 줄
3. 이어하기 → 캐릭터가 브리핑 (시스템이 브리핑하지 않는다)
4. 오늘 장면 진행
5. 세션 종료 또는 나중에 이어가기

## 대화 중 조작 (계획서 §5.3)

- 기본: 자유 입력
- 중요 분기: 선택지 카드 2~3개 + 직접 입력
- 메타 메뉴(OOC, 리롤, 장면 되돌리기)는 점 세 개 안에 숨김 — 몰입을 깨지 않게
- 스트리밍 출력 — 답변 완료 전에도 말투가 먼저 보여야 함
