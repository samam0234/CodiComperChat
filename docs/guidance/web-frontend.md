## 막는 곳

- 회원 전용 화면(대화·대화 목록·공방·마이페이지·운영자·결제)은 세 겹으로 막는다: `proxy.ts`(쿠키) → 각 페이지의 `requireUser()`(Nest에 확인) → Nest `AuthGuard`
- 로그인 뒤에는 `next`로 원래 가려던 곳에 돌아간다(사이트 안 경로만)
- 화면은 요청마다 새 nonce의 엄격한 CSP 아래에서 그려진다 — 외부 스크립트·이미지·프레임을 새로 붙이면 `proxy.ts`에 출처를 더해야 한다

## 개발할 때

- 데이터 읽기는 `lib/*.ts`(서버 전용), 쓰기는 `app/actions/*.ts`(서버 액션). 브라우저 코드에서 Nest를 직접 부르지 않는다
- 그림·열림 상자 같은 새 화면에 외부 자원을 붙이지 않는다(CSP). 그림은 중계 라우트(`app/api/characters/...`)로만 받는다(`<img>` 가 토큰을 못 붙이므로 서버가 쿠키의 토큰을 붙여 Nest에 요청, `no-store`)
- 날짜를 클라이언트 컴포넌트에서 그릴 때는 `lib/format-time.ts`(서버·브라우저가 같은 글자를 그리게) — `toLocaleString`은 하이드레이션 불일치가 난다
- 색·그림자·둥글기는 토큰만 쓴다 ([../plan/DESIGN.md](../plan/DESIGN.md))
- 시험이 쓰는 글자·역할(버튼 이름 등)을 바꾸면 `e2e/tests`도 같이 고친다
