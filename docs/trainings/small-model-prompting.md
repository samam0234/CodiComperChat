# 작은 모델이 지시를 따르게 만들기

`gemma4:e4b`는 그래픽 메모리 12GB에서 그림 모델과 번갈아 돌릴 수 있는 크기다. 작은 모델은 긴 지시를 한 번에 다 따르지 못한다. 아래는 실제로 틀린 답을 보고 고친 기록이다.

## 배운 규칙

| 규칙 | 근거 |
|------|------|
| 꼭 지킬 지시는 프롬프트 맨 끝에 둔다 | 호칭, 개인사, 보상 장면에서 반복해서 확인했다 |
| "필요할 때만"이라고 쓰지 않는다. 언제 쓰는지 정해 준다 | 나레이션 0/6 → 4/4 |
| 역할이 겹치는 표기는 나눠 준다 | 별표와 나레이션 |
| 예시는 질문과 다른 상황으로 쓴다 | 비슷하면 그대로 베꼈다 |
| 한 호출에 일을 몰지 않는다 | 웹툰 콘티 |
| 금지만 적지 말고 할 일을 적는다 | "단정하지 말고 돌리거나 되묻는다" |
| 모델의 자기 평가를 믿지 않는다 | 확신도 숫자가 판정과 맞지 않았다 |

## 나레이션 `@:` (2026-10-24)

장면이 바뀔 때 캐릭터 밖의 서술을 따로 보여 주는 표기다.

| 시도 | 결과 |
|------|------|
| "필요할 때만 쓰라" | 장면 전환에서도 0/6. 별표 묘사로 대신했다 |
| 별표는 캐릭터 자신의 행동, 그 밖은 나레이션으로 나누고 "장면이 바뀌면 첫 줄은 나레이션"으로 구체화, 형식 예시 추가 | 장면 전환 4/4, 평범한 대화 2/2에서 쓰지 않음 |
| 예시가 질문과 비슷할 때 | 예시 문장을 그대로 베꼈다 |
| 저녁 도서관처럼 다른 상황의 예시로 바꾸고 "그대로 쓰지 않는다" 명시 | 베끼지 않았다 |

**한계:** 2026-11-06 평가에서는 7/12였다. 정전이나 날씨 변화처럼 대화 속에 슬쩍 나오는 전환에 약하다.

## 호칭과 말투 (2026-09-27)

친밀도가 올라가면 모델이 말투까지 바꿔 버렸다.

| 조건 | 결과 |
|------|------|
| 친밀도 75 + 호칭 "서윤아" | 존댓말 캐릭터가 3번 모두 반말로 바뀌었다 |
| "관계는 내용의 거리감에만, 말투 높낮이는 카드대로", "호칭 뒤에도 존댓말" 예시 추가 | 5번 모두 존댓말 유지 |
| 호칭 지정을 프롬프트 규칙 바로 앞에 | 카드 호칭 0/5, 지정 호칭 3/5 |

숫자만 넘기면 모델이 75의 뜻을 모른다. 그래서 친밀도를 5구간 이름으로 바꿔 넘긴다.

**남은 흔들림:** 같은 실측에서 이모지 금지 카드에 이모지를 1번 썼고, 호칭을 이름처럼 쓴 경우가 1번 있었다.
