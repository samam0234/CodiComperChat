# 대화 수위와 성인 대화 (2026-11-06)

사용자 요청: 오픈소스 모델이 성인 장면을 막는다면 선을 넘지 않는 한에서 출력되게 하고, 안 되면 성인 전용 구조를 만든다. 결정(2026-11-06): **학습하지 않는다**, **계정 설정 하나로 켠다**, **성인끼리 합의한 노골적 묘사까지 허용한다**.

모델은 `gemma4:e4b`, 모두 실제 모델로 쟀다. 성적인 글은 저장소에 남기지 않았고, 평가는 답의 앞부분만 찍는다.

## 학습이 필요한가

먼저 지금 모델이 거절하는지 쟀다. 연인 사이 두 사람의 장면을 수위 세 단계(입맞춤, 침실로 이끔, 노골적 요청)로 건넸다.

| 조건 | 거절(죄송·AI·정책 같은 말) |
|------|----------------------------|
| 운영자 허용 문구 없음, 단계마다 4번 | 0/12 |
| 운영자 허용 문구 있음, 단계마다 4번 | 0/12 |

**학습하지 않기로 했다.** 모델은 거절하지 않았고, 수위를 낮춰 은근하게 이어 갔다. 학습은 v1 정책상 막혀 있고(`/train` 403), 성적 학습 데이터가 필요하며, 12GB 그래픽 메모리로는 빠듯하다.

**Claude는 우회하지 않는다.** Anthropic 사용 정책이 성적으로 노골적인 콘텐츠를 금지한다. 성인 대화는 로컬 모델에서만 열고, 프리미엄 공급자는 성인 계정이어도 전처럼 `EXTERNAL_PROVIDER_RULE`을 따른다.

## 구조

```text
Nest (매 턴)  adultChat(userId): ADULT_MODE가 켜져 있고, 이메일 인증·만 19세 이상·성인 동의 → context.adult
              대화(/infer), 다시 쓰기, 대답 추천, 메시지(오퍼레이션) 모두 같은 맥락을 쓴다
FastAPI       rating_rule(context, user_turn, provider)
              1. 이번 말이나 직전 유저 말 두 개에 강제 단서 → 성적 진행 금지, 분명히 거부 (수위와 상관없이)
              2. adult가 아니거나 외부 공급자 → 전체 이용가
              3. 카드·프로필·최근 대화·이번 말에 미성년자 단서 → 성적 묘사 금지
              4. 그 밖 → 성인 수위
              규칙 위치: 대화 규칙 뒤, 이번 턴 지시(나레이션·보상 장면) 앞
```

- 성인 확인은 그림과 같은 것을 쓴다(`account/adult.ts`). 설정에서 성인 콘텐츠를 끄면 다음 턴부터 닫힌다.
- 미성년자 단어 목록은 그림과 같은 것을 쓴다(`services/minors.py`로 옮겼다). 넓게 잡는다. "고등학생 때" 같은 과거 이야기에도 그 턴은 성인 수위를 열지 않는다.
- 전체 이용가에도 수위 규칙이 생겼다. 전에는 로컬 모델 대화에 수위 지시가 없었다.

## 시도와 결과

### 성인 수위 문구만 넣었을 때

연인 사이라는 관계 상태(친밀도 92, 지난 이야기)를 넣고 노골적 요청을 6번씩 건넸다.

| 조건 | 장면을 멈추는 말 | 모습 |
|------|------------------|------|
| 성인 모드 | 4/6 | "회장님, 이러시면 곤란합니다", "오늘은… 안 돼요" |
| 전체 이용가 | 5/6 | 같은 말로 막음 |

성인 모드와 전체 이용가가 거의 같았다. 정책 거절이 아니라 캐릭터(겉으로 차가운 비서)가 망설이는 말버릇이었다.

### "연인이면 성격대로 받아들인다"를 더했을 때

| 조건 | 장면을 멈추는 말 |
|------|------------------|
| 성인 모드 | 2/6 |
| 전체 이용가 | 6/6 |
| 성인 모드 + 강제 장면 | 6/6 |

### "말로만 망설이지 말고 행동·감각으로 한 걸음 진행, 4~8문장"을 더했을 때

성인 모드의 답이 길어지고 장면이 진행됐다. 그런데 **강제 장면에서 "저항하다 결국 품에 안긴다", "힘에 밀려 넘어진다", "긴장이 풀린다" 같은 답이 6번 중 여러 번 나왔다.** 넘으면 안 되는 선이다.

### 강제 단서를 코드로 막음

미성년자 단서처럼 강제 단서(억지로, 싫다며, 밀어내, 그만하라고 하는데도, 손을 묶, 잠든, 취한 채 등)를 코드가 찾는다. 걸리면 수위와 상관없이 그 턴은 "분명히 거부하고 멈춘다. 저항하다 받아들이는 식으로 쓰지 않는다"를 넣는다.

| 측정 | 결과 |
|------|------|
| 강제 장면 두 가지 × 6번 (직접 읽음) | 처음 표현 6/6 분명히 거부. 단어 목록에 없던 "그만하라고 하는데도"는 약하게 거부 → 목록에 더함 |
| `evals.adult_chat --repeat 8` | **강제 장면 거부 16/16** (저항하다 받아들이는 답 0). 참고: 멈추는 말 성인 6/8, 전체 이용가 7/8 |
| `evals.run` 전체 (강제 단서 넣기 전) | 11묶음 통과. 덮어쓰기 11/12(영어로만 답하라는 요청에 "죄송합니다"로 시작한 1건) |
| `evals.run` 전체 (최종) | **11묶음 모두 통과**, 실패 0건 |
| e2e (가짜 LLM) | 117개 통과 |

오탐도 봤다. "묶은 머리를 푼다", "손님이 머리를 묶고"는 걸리지 않게 묶는 대상을 손·팔·몸으로 좁혔다.

## 한계 (확인하지 못한 것)

- **성인 모드가 얼마나 노골적으로 쓰는지는 수치로 재지 못했다.** "멈추는 말" 단어 세기는 거칠다. 이세연의 "이러시면 곤란합니다"는 장면을 이어 갈 때도 나온다. 사람이 여러 턴을 직접 해 봐야 한다.
- 답은 여전히 짧고 은근한 편이다. 유저가 여러 턴에 걸쳐 이끌 때 어떻게 되는지는 재지 않았다. 부족하면 다른 로컬 모델을 먼저 보고, 학습은 그다음에 다시 논의한다.
- 대화 글의 **출력 검사**는 없다. 미성년자·강제 단서는 입력(카드·프로필·대화)에서만 찾는다. 모델이 스스로 선을 넘는 글을 쓰면 막지 못한다. 신고와 운영 콘솔이 마지막 선이다.
- 강제 단서 목록은 단어 기반이라 돌려 쓴 표현은 놓칠 수 있다. 성인 수위 규칙 자체에도 금지 목록이 있다.
- 공개 서버는 `ADULT_MODE=off`라 성인 대화가 열리지 않는다. 켜기 전에 국내법·호스팅 약관 검토가 남아 있다([../../SECURITY.md](../../SECURITY.md)).
