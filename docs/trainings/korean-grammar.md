# 대화 답·추천의 한국어 맞춤법 (2026-11-12)

가중치를 다시 가르치지 않았다. `/train`은 그대로 403이다. 작은 모델은 지시가 늘면 나레이션·말투처럼 이미 맞춰 둔 규칙을 놓친다. 그래서 프롬프트에 틀린 철자 예시를 넣지 않고, 글이 나가기 직전에 배운 오류만 고친다.

## 로직 구조

```text
모델 원문
  ├─ 배운 철자 (grammar_pairs.json, 긴 것부터)
  ├─ 안돼·이에요/예요·ㄹ받침 수 있/없·조사가 두 번·요요·문장부호 띄어쓰기
  └─ 괄호 조사 이(가)
        │
        ▼
대화 답 · 추천 · 다시 쓰기 · 월드 답
```

## 배운 것

| 오류 | 고친 문장 |
|------|-----------|
| 됬, 되요, 되서, 안되요 | 됐, 돼요, 돼서, 안 돼요 |
| 아니예요, 집예요, 친구이에요 | 아니에요, 집이에요, 친구예요 |
| 갈수있어, 것같, 웬지, 몇일, 오랫만, 금새 | 갈 수 있어, 것 같, 왠지, 며칠, 오랜만, 금세 |
| 집을를, 오늘은는, 유지성이(가) | 집을, 오늘은, 유지성이 |

이미 맞는 문장(아이가, 한지우가, 어떡해, 할 수 있어요)은 바꾸지 않는다. 고친 문장에 같은 교정을 다시 해도 글이 같다. 단위 시험이 이 목록을 전부 맞는지 본다.

## 로컬 모델 표본 (gemma4:e4b, 2026-11-12)

평가 바리스타(한지우)에게 같은 날 네 질문을 한 번씩 보냈다. 교정 전후가 달라진 답은 0/4다.

| 질문 | 원문 |
|------|------|
| 지금 뭐 해? | 별거 안 해요. 그냥 가게 정리하고 있었어요. |
| 오늘 기분 어때요? | 글쎄요... 그냥, 평소 같네요. 손님은 오늘 기분이 좀 어떠신가요. |
| 커피 추천해 줄래요? | 손님은 평소에 어떤 걸 좋아하세요...? |
| 비가 오네요. | 네, 비가 많이 오네요. 우산은 챙기셨어요? |

추천 세 줄도 이 교정에서 더 바뀌지 않았다. 이 네 답은 처음부터 배운 오류에 걸리지 않았다. 모델이 그 오류를 내면 같은 규칙이 항상 고친다. 네 질문으로 모든 문장이 자연스럽다고 말하지는 않는다.
