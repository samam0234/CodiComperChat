# 기억과 개인사 환각

제품의 차별점은 모델이 아니라 **무엇을 기억하고 무엇을 숨기느냐**다(계획서). 작은 모델은 긴 카드의 뒷부분을 놓치고 빈칸을 지어내기 쉬워, 넣는 양을 줄이고 근거가 없는 것을 막는 쪽으로 만들었다.

## 페르소나 지식 검색 (2026-09-26)

카드 원문 전부 대신 **짧은 핵심 + 이번 대화와 관련된 조각**만 넣는다.

| 결정 | 이유 |
|------|------|
| 글자 2-gram BM25 + 키워드 보너스 | 형태소 분석기 없이 조사가 붙어도 맞고 사전 관리가 필요 없다. 문서가 수십 개 규모다 |
| 벡터 DB를 쓰지 않음 | 지금 규모에 필요 없다. 같은 인터페이스로 나중에 바꿀 수 있게 뒀다 |
| 조각 최대 3개, 합 700자 | 많이 넣으면 최근 대화가 잘린다 |
| 질의는 이번 말 + 직전 두 턴(가중 0.3·0.45) | "그거"처럼 이어지는 말도 찾으려고 |
| 키워드 보너스는 이번 말에서 맞으면 전액, 직전 대화에서만 맞으면 30% | 지난 화제에 끌려가지 않게 |
| 검색을 Nest에 둠 | 맥락 조립이 Nest 책임이다. FastAPI 계약은 바꾸지 않았다 |

**켬/끔 비교 (실제 `gemma4:e4b`, 질문당 8개):**

- 시험용 조각(보리차, 새벽 달리기)이 든 파일: 켠 쪽은 6번 모두 그 설정대로 말했고, 끈 쪽은 설정에 없는 일과를 지어냈다.
- 표본이 작아 통계적 차이라고 단정하지 않는다. 2턴 대화의 자연스러움은 차이를 확인하지 못했다.

**이세연 지식 파일(2026-11-04):** 카드 원문의 내용만 조각으로 나눴다. "커피 어떻게 드세요"에 커피 취향 조각이 4.24점으로 뽑히는 것을 `persona:search`로 확인했다. 대화 품질을 파일 전후로 비교하지는 않았다.

## 개인사 환각 막기 (2026-10-15)

"형제 있어요?"처럼 설정에 없는 개인사를 물으면 작은 모델은 지어낸다. "없어요"라고 단정하는 것도 지어내는 것이다.

1. 유저 말의 주제가 설정에 근거가 있는지 Nest가 본다. "나이 23세"가 있으면 그대로 답하게 둔다.
2. 근거가 없으면 프롬프트 맨 끝에 "단정하지 말고 돌리거나 되묻는다"를 넣는다.
3. 답을 받은 뒤 `/ground-check`로 지어냈는지 판정하고, 그렇다면 최대 2번 다시 쓴다.

| 측정 | 결과 |
|------|------|
| 판정 정답 세트(정상 2, 지어냄, 반말, 메타) × 3회 | 15회 모두 맞음 |
| 단정한 답 / 말을 돌린 답 | 4/4 걸림 / 4/4 통과 |
| `grounding` 평가 2026-10-15 | 12/12 |
| `grounding` 평가 2026-11-06 | 11/12. 반려동물 질문에 "없다"고 단정한 1건 |

"대학생"이라는 말만으로는 어느 학교인지 근거가 아니다. 근거의 범위를 좁게 본다.

## 이야기 상태 정리

대화 3번(메시지 6개)마다 뒤에서 요약, 친밀도, 복선을 정리한다. 답 속도에 영향을 주지 않는다.

| 결정 | 이유 |
|------|------|
| 복선 최대 5개, 끝난 일 최근 20개 | 맥락 예산 |
| 표현만 다른 복선은 글자 쌍 겹침(Dice)으로 거른다 | 실측에서 이미 열린 약속을 표현만 바꿔 또 열었다 |
| 친밀도 변화에 상한을 둔다(`MAX_DELTA`) | 한 번에 크게 뛰지 않게 |
| 판정·요약은 시드를 고정한다 | 같은 입력에 같은 결과. 연기에는 걸지 않는다(매번 같은 말을 한다) |
