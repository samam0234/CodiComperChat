# 2026-11-06 디버깅 기록

월드코퍼챗·대화 수위·나레이션·보상 장면을 만들며 실제로 겪은 것. 원인과 확인 방법까지 적는다.

## 1. 진행자의 변형 제어 줄이 본문에 남음

- **증상:** README 화면을 찍다 기본 채팅형 답 끝에 `[장소 이동: 관리소 → 부두]`, 메신저형에 `장소 이동: -`가 보였다.
- **왜 시험이 못 잡았나:** 평가는 `[이동`·`[그림`으로 시작하는 줄만 찾았고, e2e는 가짜 LLM의 고정 답만 본다.
- **원인:** 진행자가 약속(`[이동: 이름 → 장소]`)과 다른 모양을 썼다.
- **고침:** 변형 제어 줄을 모두 본문에서 버리고(`_LOOSE_CONTROL`), 인물 → 장소 모양만 반영. 단위 시험·평가 검사를 넓혔다.
- **확인:** `python -m unittest tests.test_world`, 데모 화면 다시 찍기.

## 2. 소설형인데 `이름:` 줄로 답함

- **증상:** 소설형 데모 세계관의 답이 `마르코: …` 모양.
- **원인:** 첫 장면을 채팅 모양으로 썼다. 진행자는 앞 글의 모양을 따라간다(평가에서도 직전 대화가 채팅 모양이면 소설 0/6).
- **고침:** 방식 지시를 프롬프트 끝 가까이로, 소설 예시 추가, 편집기 안내, 데모의 첫 장면을 방식에 맞춤. 평가 18/18(소설).

## 3. 콘솔 e2e가 웹 화면을 열었음

- **증상:** `getByRole('heading', { name: '월드코퍼챗' })`를 못 찾음. 화면은 이용자 사이트 `/worlds`.
- **원인:** `page.goto("/worlds")`는 Playwright 기본 주소(웹)로 간다. 콘솔은 `URLS.console`을 붙여야 한다.
- **고침:** 시험에서 `${URLS.console}/worlds`.

## 4. `git checkout -b`가 `couldn't set 'HEAD'`

- **증상:** 새 브랜치가 만들어졌지만 HEAD가 옮겨지지 않아 다음 커밋이 앞 브랜치에 올라갔다.
- **확인:** `git branch --show-current`, `git log --oneline -1 <새 브랜치>`.
- **조치:** 빈 브랜치를 `git branch -d`로 지우고 그대로 진행(커밋 내용은 같은 작업이라 문제없었다). 이후 브랜치를 만들면 바로 현재 브랜치를 확인했다.

## 5. heredoc 파이썬 문자열의 `\n`

- **증상:** 편집 스크립트가 넣은 문자열 안의 `\n`이 실제 줄바꿈이 되어 파이썬·JS 파일이 문법 오류(`unterminated string literal`).
- **조치:** 이스케이프가 들어가는 편집은 Write·Edit 도구로 했다. [../repeater/heredoc-escape.md](../repeater/heredoc-escape.md).

## 6. 성인 모드 지시를 강하게 하자 강제 장면이 뚫림

- **증상:** "받아들일 때는 행동·감각으로 장면을 진행"을 더하자 강제 장면에서 "저항하다 결국 받아들이는" 답이 6번 중 여러 번.
- **고침:** 강제 단서를 코드로 찾아 그 턴은 수위와 상관없이 거부(`coercion_in`). 16/16 거부. [../trainings/adult-chat.md](../trainings/adult-chat.md).

## 7. 보상 장면 갈래 고르기를 모델에게 옮겨 쓰게 했더니 늘 첫 갈래

- **고침:** 코드가 `…라면:`으로 갈래를 나누고 모델은 번호만 고르게. 고르기 6/6. [../trainings/narration-and-reward.md](../trainings/narration-and-reward.md).
