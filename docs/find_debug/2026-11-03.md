## 1. 개발 서버를 켠 전체 e2e 시간 초과 (`chat.spec.ts:31`은 메모리)

- **증상**: 미병합 작업 맨 위 브랜치에서 전체 e2e가 108/112, 15.4분. 네 건 모두 시간 초과다.
  - `chat.spec.ts:31`: "답하는 중"이 15초 넘게 보임
  - `operations.spec.ts:55`, `:92`: 주소가 `/mind`, `/diary`로 바뀌지 않음
  - `reports.spec.ts:6`: "복구하기"가 계속 보임
- **환경**: 개발 서버 3000·4000·8000이 켜져 있었고, 실행 직후 남은 RAM은 16GB 중 약 0.4GB였다.
- **따로 돌린 결과**:
  - 네 건만: `chat.spec.ts:31` 실패, 나머지 셋 통과(4.3분)
  - `chat.spec.ts:31 --repeat-each=3`: 3번 모두 통과(2.3분)
- **이력**: 같은 날 전체 실행 3번 모두 `chat.spec.ts:31`이 실패했다. 다른 실패는 실행마다 달랐다.
- **원인**: 당시에는 확정하지 못했다. 시험이 끝난 뒤 웹 로그에 `SyntaxError: Unexpected end of JSON input`(`app/api/characters/[id]/chat/route.ts:11`의 `await request.json()`)이 찍혔다. 브라우저가 요청을 포기한 뒤에야 처리가 시작됐다는 뜻으로 보였다. 아래 2장에서 서버를 끈 실행이 `chat.spec.ts:31`을 통과해, 이 시험의 반복 실패는 코드 결함이 아니라 메모리 부족으로 본다.
- **해결**: 개발 서버(3000·4000·8000)를 끄고 다시 돌렸다. `chat.spec.ts:31`은 전체 실행 안에서 7.3초에 통과했다. 서버를 끈 상태에서도 실패하면 코드 문제로 보기로 했으므로, 이번 통과로 이전 3번의 실패는 메모리 부족으로 본다. 시간 제한은 늘리지 않았다.
- **재현**:

  ```bash
  npm run test:e2e > e2e/.tmp/full.log 2>&1; echo "exit $?"
  npm run test:e2e -- tests/chat.spec.ts:31 --repeat-each=3
  ```

- **다음**: 112건이 모두 통과하기 전에는 `develop`에 병합하지 않는다. [../TASKS.md](../TASKS.md) T01, T03.

## 2. 서버를 끈 전체 e2e는 111/112 (2026-11-03, 병합 보류)

- **증상**: 개발 서버를 끈 뒤 `npm run test:e2e`가 17.9분, 111 통과, 1 실패.
  - 실패: `webtoon.spec.ts:95`. 오퍼레이션 메뉴에서 웹툰을 눌렀는데 주소가 `/chat`에 60초간 머물렀다. 실패 시점의 접근성 트리에는 오퍼레이션 메뉴가 닫혀 있고 대화 화면이 그대로였다.
  - `chat.spec.ts:31`은 통과(7.3초).
- **환경**: 서버를 끄기 직전 남은 RAM 약 374MB, 끈 뒤에도 약 337MB, 실행이 끝난 뒤 약 334MB(전체 16160MB). 메모리를 많이 쓰던 것은 Chrome·Cursor·VS Code·Discord·Docker·WSL·Claude였다. Ollama(11434)는 켜 둔 채였다. 그림 엔진(7860)은 꺼져 있었다.
- **따로 돌린 결과**: `npm run test:e2e -- tests/webtoon.spec.ts:95`는 1.9분(시험 자체 22.4초)에 통과.
- **원인**: 같은 날 전체 실행마다 실패 시험이 달랐다. 이번에도 이전의 `chat`·`operations`·`reports`가 아니라 `webtoon` 화면 이동이었다. 혼자 돌리면 통과하므로 코드 결함으로 확정하지 않았다. `next dev`가 바쁠 때 메뉴 클릭의 화면 이동이 늦거나 빠지는 부하 실패로 본다.
- **해결**: 시간 제한은 늘리지 않았고, 시험을 건너뛰지 않았다. 112건이 아니어서 `develop` 병합은 하지 않았다.
- **재현**:

  ```bash
  npm run test:e2e > e2e/.tmp/full.log 2>&1
  npm run test:e2e -- tests/webtoon.spec.ts:95
  ```

## 3. 원인 확인과 해결 (2026-11-04)

- **확인**: `develop`에서 `next dev`로 다시 돌리니 111/112(11.0분), 이번에는 `quest.spec.ts:212`가 실패했다. 실패 모양이 전부 "눌렀는데 15초 안에 반응 없음"이었다.
