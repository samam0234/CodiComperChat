## 주 내용

- AI 서비스에 월드코퍼챗 진행자(`/world/turn`)와 파트 판정(`/world/part-check`)을 더했다
- 진행자 답 끝의 제어 줄(`[그림: 이름표]`, `[이동: 이름 → 장소]`)은 코드가 떼어 내고, 없는 이름표·인물·장소는 버린다
- 실제 모델 평가 `evals.world_turn`과 단위 시험 `tests/test_world.py`를 더했다

## 상세

**배경**
사용자가 월드코퍼챗을 요청했다(2026-11-06): 1:1 대화가 아니라 한 세계관 안에서 여러 캐릭터와 이어 가는 이야기, 대화 방식 4가지(기본 채팅·비주얼노벨·소설·메신저), 파트, 코퍼맵, 이벤트 미니게임.

**변경 범위**
`services/ai/app/{schemas,services,routes}/world.py`, `app/main.py`, `evals/world_turn.py`, `tests/test_world.py`.

**기술 포인트**
진행자는 등장인물 명단 안의 이름만 쓰고 유저 대사를 대신 쓰지 않는다. 수위 규칙(전체 이용가·성인·미성년자·강제 단서)은 1:1 대화와 같은 것을 쓴다. 파트 판정은 퀘스트 판정처럼 근거 인용이 대화에 그대로 있을 때만 통과한다. 처음 평가에서 소설 방식이 9/12였다(직전 대화의 `이름:` 모양을 따라 씀). 방식 지시를 프롬프트 끝으로 옮기고 소설 예시를 더해 18/18이 됐다.

**안 한 것**
요약(지난 이야기)은 마친 파트 기록만 쓴다. 장소 이동은 모델이 거의 쓰지 않는다(0/24).
