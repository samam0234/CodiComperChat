## 주 내용

- 대화 글 꾸미기: *기울임* **굵게** ***굵은 기울임*** ~취소선~ `코드` ```상자``` ```InfoBox 정보창``` # 제목(1~3개) --- 구분선 > 인용 >여백 * 목록 @이름 @서술 {{user}}
- 내 말·캐릭터 답·공방 테스트 대화에 모두 적용 (components/chat-text.tsx)
- 모델에게 보내는 글의 {{user}}도 내 프로필 이름으로 바꾸고, 답 꾸밈 규칙(규칙 7)을 알려 줌

## 상세

**배경**
사용자 요청("대화 명령어 추가기능 … 텍스트 명령어 기능들을 적용")에 따라 만들었다. 붙여 준 표기 목록을 그대로 따랐다.

**변경 범위**
apps/web(lib/chat-format.ts, components/chat-text.*, 채팅·공방 테스트 화면), services/ai(inference.py), e2e/tests/format.spec.ts, docs

**기술 포인트**
- 글을 HTML 문자열로 만들지 않고 파서가 '무엇을 그릴지'를 돌려주면 React 요소로만 그린다 — 글 속 태그는 실행되지 않는다(e2e로 확인)
- 정규식 깃발 s·u와 뒤돌아보기는 target(ES2017)에 걸려 new RegExp(String.raw)로 만들었다
- ~는 글자·숫자 바로 옆이면 말투로 보고 취소선으로 읽지 않는다
- InfoBox는 <details open>이라 접고 펼 수 있고 키보드로도 된다
- @이름 뒤 줄들은 빈 줄이나 다른 표기가 나올 때까지 그 사람의 말로 묶는다
- 내레이터는 캐릭터 설정의 '고급 설정'에서 정하는 기능이라고 했지만 설정 화면은 만들지 않고 @ 표기만 그린다

**안 한 것**
캐릭터별 내레이터 지정 화면, 대화 목록·저장한 대화 목록 미리보기의 꾸밈 제거(지금은 표기 문자가 그대로 보인다), 입력창 꾸미기 도구 모음
