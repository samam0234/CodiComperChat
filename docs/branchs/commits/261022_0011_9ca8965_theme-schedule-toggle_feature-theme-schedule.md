## 주 내용

- 헤더의 캐릭터 만들기 옆(비로그인은 시작하기 옆)에 해·달 밝기 버튼
- 기본 테마를 시간표로: 한국 시각 오전 7시부터 밝기 모드, 오후 10시부터 다크 모드. 화면을 열어 둔 채 시간이 지나면 저절로 바뀜
- 설정 > 화면: 시간에 따라 자동 / 밝기 모드 영구 설정 / 다크 모드 영구 설정 (기기 설정 따르기는 없앰)
- 헤더 버튼은 자동일 때 다음 전환까지만 바꾸고(theme_override 쿠키), 영구 설정일 때는 영구 설정을 반대쪽으로 바꿈
- 개인정보처리방침 쿠키 목록에 theme_override 추가

## 상세

**배경**
사용자 요청("헤더 부분에 테마설정 기능 … 캐릭터 만들기 버튼 옆에다 테마설정 버튼 … 밝기 모드: 한국시간 오전 7시부터, 다크 모드: 오후 10시부터 … 설정에서 밝기 모드 영구 설정, 다크모드 영구 설정")에 따라 만들었다.

**변경 범위**
apps/web(lib/theme-schedule.ts·theme.ts, actions/preferences.ts, components/theme-toggle.tsx·site-header, layout, settings, privacy), e2e/tests/theme.spec.ts·mypage.spec.ts, docs

**기술 포인트**
- 시간표 계산(lib/theme-schedule.ts)을 서버(첫 화면)와 브라우저(열어 둔 채 시간이 지날 때)가 함께 쓴다. 기기 시간대와 상관없이 epoch에 9시간을 더해 한국 시각을 잡는다
- 서버가 data-theme을 늘 정해 보내 첫 화면 깜빡임이 없다. 브라우저는 다음 전환 시각(또는 잠깐 바꾼 것이 끝나는 시각)에 타이머로 다시 계산
- 잠깐 바꾸기 쿠키 값은 '밝기.끝나는 시각(ms)'. 끝나는 시각은 브라우저가 계산해 보내고 서버는 지금부터 이틀 안쪽만 믿는다
- 예전 쿠키 값 system은 자동으로 본다(따로 옮기지 않아도 된다)
- e2e는 page.clock으로 브라우저 시계를 고정·빨리 감기 해 낮·밤·오후 10시·오전 7시 전환·영구 설정을 시험

**안 한 것**
운영 콘솔(console/)은 이 시간표를 쓰지 않고 기기 설정을 따른다
