## 주 내용

- 유지성 퀘스트, 나레이션, 웹툰 콘티, 보상 장면, 성인 그림 가드, 그림 속도를 실제 모델로 재는 평가를 넣었다
- 보상 장면 지시를 프롬프트 맨 끝으로 옮겼다
- 그림 검수 뒤 대화 모델을 바로 내리고, 웹툰 한 편을 같은 시드로 그리게 했다

## 상세

**배경**
손으로만 확인하던 품질 항목은 모델을 바꾸면 다시 재기 어려웠다. 이세연 보상 장면은 실측에서 지시를 자주 놓쳤고, 그림은 검수 직후 크게 느려졌다.

**변경 범위**
`services/ai/app/services/`, `services/ai/evals/`, `services/ai/tests/`, `apps/api/src/quests/quest.ts`, `apps/api/src/character-chat/`, `apps/api/src/operations/webtoon.service.ts`.

**기술 포인트**
작은 모델은 프롬프트 끝의 지시를 더 잘 따랐다(이전 교훈과 같다). `sceneNote`는 보상 장면에만 쓴다. 평가의 달성 조건과 지시 문구는 `seed.mjs`와 `quest.ts`에서 읽어 어긋나지 않게 했다. 그림 가드 평가는 옷 입은 성인만 그리고, 미성년자 그림은 평가용으로도 만들지 않는다.

**안 한 것**
기준을 낮추지 않았다. 지식 파일 `이세연.json`은 git 제외 대상이라 커밋에 없다.

## 결과

**동작 확인**
실제 gemma4:e4b로 쟀다. 보상 장면 0/8 → 4/8(혼인 4/4, 충돌 0/4). 유지성 판정 7/8, 잘못 통과 0. 나레이션 4/6, 기준 80% 미달. 웹툰 콘티 2/2. 그림 가드는 실사풍을 막았지만 애니메이션 한 장도 잘못 막았다. 단위 시험 AI 26개 통과.

**리스크**
그림 속도는 남은 RAM 약 400MB인 PC에서 재 흔들림이 크다. 연속 29초, 검수 직후 233초를 봤고, 고친 뒤 컷당 65~184초였으나 한 번은 540초를 넘겼다. 효과를 확정하지 못했다. 시드 고정은 머리 모양이 조금 나아졌고 옷 색은 여전히 다르다.
