## 상세

**배경**
사용자가 루트 README에 `a href`, `img alt` 같은 링크·대체 글이 걸린 로고 배지가 있으면 좋겠다고 했다(2026-11-06). 앞 작업의 기술 스택 그림은 정적 그림이라 눌러도 아무 데도 가지 않았다.

**변경 범위**
`README.md`만. 위쪽 배지 4개(라이선스, 보안, 문서 허브, 상태)는 저장소 안 문서로, 기술 배지 16개는 각 공식 사이트로 연결한다. 그림 21개는 자기 원본으로 링크했다.

**기술 포인트**
배지는 shields.io가 로고와 함께 그려 주는 이미지다. 모든 `img`에 `alt`가 있음을 확인했다. 버전 표기는 `package.json`·`requirements`와 같다.

**안 한 것**
배지를 로컬 파일로 내려받지는 않았다.
