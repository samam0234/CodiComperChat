## 주 내용

1:1 대화 답을 웹소켓으로 토큰이 나오는 대로 보여 준다. 모델이 느린 이유를 소켓 부재로 보지 않고, 다 만든 뒤에야 그리던 화면만 바꿨다.

## 상세

### 배경

로컬 모델은 원래 토큰을 하나씩 만든다. 그 조각을 서버가 모았다가 한 번에 보내서 화면이 끝까지 비어 있었다. 웹소켓을 연다고 추론이 여러 갈래로 나뉘거나 빨라지지는 않는다.

### 변경 범위

- FastAPI `/infer/stream`이 로컬 Ollama 조각을 NDJSON으로 넘긴다. 호스팅 모델은 답을 한 덩어리로 보낸다.
- Nest가 일회용 표를 만들고 `/ws/chat`으로 조각을 전달한다. 개인사 검사가 답을 고치면 화면 글을 바꾼 뒤 저장한다.
- 웹은 그 소켓에 붙여 말풍선을 채운다. CSP에 API 출처를 연다.

### 기술 포인트

브라우저는 httpOnly 쿠키를 API 주소로 보내지 못하므로, 로그인한 POST로 30초짜리 표를 받는다. 표는 한 번만 쓴다. 월드 플레이와 명령어는 예전 HTTP 그대로다.

### 안 한 것

모델 병렬 처리나 부하 분산은 하지 않았다. 운영 서버는 다시 올리지 않았다. 기획 원본과 포트폴리오는 다음 커밋에서 맞춘다.

## 결과

### 동작 확인

Ollama 스트림 단위 시험과 표·NDJSON 파서 시험을 통과했다. 브라우저에서 실제 모델 답을 다시 보지는 않았다.

### 리스크

개인사 검사가 답을 고치면, 먼저 보인 글이 잠깐 있다가 바뀐다. 공개 API는 이 소켓을 아직 모른다.

### 후속

문서와 포트폴리오를 맞춘 뒤 develop, main에 병합한다.
