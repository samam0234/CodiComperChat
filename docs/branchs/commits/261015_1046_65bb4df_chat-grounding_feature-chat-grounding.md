## 주 내용

- `character-chat/grounding.ts`: 개인사 주제 10종(가족·고향·학교·나이·연애·친구·취미·반려동물·과거·외모) 감지와 "설정에 근거가 있는가" 판정
- 근거 없는 주제를 물으면 `context.ungroundedTopics`로 FastAPI에 넘기고, 프롬프트 맨 끝에 단정 금지를 못 박음
- FastAPI `/ground-check` + 다시 쓰기(`retryNote`): 단정한 답을 가려내 최대 2번 다시 쓰게 하고, 끝내 단정하면 안전한 말로 대체
- 공방 3턴 테스트에도 같은 가드 적용
- 가드 단위 테스트 4개, API 문서·NAVIGATION_IA

## 상세

**배경**
사용자 요청("먼저 하면 좋은 것"). 앞선 작업에서 엑스트라를 적용하지 않은 대화에서도 유지성이 "여동생이 있어요"처럼 설정에 없는 개인사를 단정하는 경우가 있었고, 기존 `guard-unwritten` 조각과 규칙만으로는 막히지 않았다.

**변경 범위**
apps/api(character-chat, persona-rag, studio), services/ai(context 스키마, inference, ground 스키마·서비스·라우트), docs

**기술 포인트**
- 기준선(수정 전): 개인사 8문항 × 2회 = 16번 중 5번 지어냄 — 취미 "산책"·"책 읽기", 반려동물 "키우는 건 없어요" 2번, 나이 "스물셋". 이 중 나이는 카드의 부가 프로필에 "나이 23세"가 있어 사실 지어낸 게 아니었다 → "근거 있는 주제는 그대로 답한다"를 규칙에 넣었다.
- 근거 판정에서 안전장치 조각(`guard-*`)은 "없다는 사실"을 적은 글이라 뺀다. "대학생"이라는 말만으로는 어느 학교인지 알 수 없어, 학교 질문은 학교 이름이 적혀 있어야 근거로 친다.
- 모델이 지시를 어기는 경우를 위해 의심 턴에서만 판정 모델이 답을 한 번 더 본다. 근거 있는 주제와 개인사가 아닌 말에는 호출하지 않아 평소 응답 속도는 그대로다. 검사가 실패하면 원래 답을 쓴다(대화를 막지 않는다).
- 판정 모델 점검: 지어낸 답 3개(스물세 살, 책 읽기, 취미 없음)는 invented, 말 돌린 답은 not invented로 정확히 구분했다.

**안 한 것**
- 개인사 아닌 영역(세계관 사실 등)의 환각, 판정 모델 정확도 평가 세트 확장

- 수정 후 8문항 × 3회 = 24번: 구체적으로 지어낸 답 0번(나이는 카드대로 "스물세 살"), "딱히 꾸준히 하는 취미는 없어요"류 없음 단정 1번
