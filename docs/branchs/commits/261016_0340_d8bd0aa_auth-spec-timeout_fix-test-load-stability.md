## 주 내용

- `auth.spec.ts`의 비밀번호 규칙 시험 3개에서 `await import('./auth.dto.js')`를 파일 맨 위 import로 옮김

## 상세

**배경**
API 단위 테스트가 가끔 1개씩 실패했다(이번 작업에서 두 번, 각각 e2e 직후). 혼자 돌리면 수십 번 통과해 원인을 못 잡다가, 3개를 동시에 돌려 PC를 바쁘게 하자 재현됐다.

**변경 범위**
apps/api/src/auth/auth.spec.ts

**기술 포인트**
- 실패한 시험은 "너무 흔하거나 단순한 비밀번호는 거절한다"였고 걸린 시간 5,715ms — vitest 기본 제한 5초를 넘었다. 검사 자체는 1ms짜리이고, 시험 안에서 처음 모듈을 불러오는(변환 포함) 시간이 바쁠 때 5초를 넘었다. 맨 위 import로 옮기면 불러오기는 파일 준비 단계에서 끝나 시험 시간에 잡히지 않는다.
- 같은 부하에서 다른 시험은 모두 2초 미만이었다.
