## 주 내용

- 기본 대화 출력 상한을 첫 답 384, 다음 답 320토큰으로 조정했다.
- 장면 전환을 실제 모델 지연 평가에 추가했다.
- 스트리밍 최종 답에 완결된 대사와 닫힌 따옴표가 전달되는지 확인했다.

## 상세

**배경**

웹에서 문장 중간 종료가 보고되었다. 이전 96토큰 상한은 행동 묘사와 대사를 완결하기에 부족할 수 있다.

**변경 범위**

AI 출력 예산, 관련 회귀 시험, 실제 모델 평가와 구조·실측 문서.

**기술 포인트**

짧은 답 지시를 유지하면서 생성 여유를 늘렸다. 프롬프트 완결 지시 추가 실험은 회상 실패로 채택하지 않았다.

## 결과

**동작 확인**

관련 단위 시험 31개 통과. 최종 실제 모델 평가 8회 모두 정상 종료, 로컬 GPU 완료 2.640~3.391초. 기억 회상 두 번 통과.

**리스크와 후속**

운영 서버 배포와 CPU 시간 측정이 필요하다. 출력 토큰 상한의 증가는 장비와 응답 길이에 따라 생성 시간을 늘릴 수 있다.
