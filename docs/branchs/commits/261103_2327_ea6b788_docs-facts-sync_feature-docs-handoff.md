## 주 내용

- 시험 수, 테이블 수, Next 버전, 호스팅 결정이 문서마다 다른 곳을 실제 값으로 맞췄다
- 클릭 프로와 나이 확인을 기능·화면·DB·모델 문서에 반영했다
- 전체 e2e 실패 경과를 디버그 일지와 재발 지식에 남겼다

## 상세

**배경**
문서가 코드와 어긋나 있으면 Cursor가 잘못된 값을 믿고 작업한다. 예: AI 모델 문서가 "18세 미만을 막지 않았다"고 적고 있었다.

**변경 범위**
`docs/`, 루트 `README.md`, `THIRD_PARTY_NOTICES.md`, `e2e/README.md`, `apps/api/README.md`, `apps/web/README.md`. 코드는 바꾸지 않았다. 기획 원본은 건드리지 않았다.

**기술 포인트**
값은 저장소에서 다시 읽었다(마이그레이션 33개, 모델 28개, e2e 112개, unittest 22개, lock의 Next 16.4.4). `CURRENT_STACK.md`의 어긋난 표 칸도 바로잡았다.

**안 한 것**
`LICENSE`. 저장소 전환 뒤 사용자 승인을 받아 고친다.
