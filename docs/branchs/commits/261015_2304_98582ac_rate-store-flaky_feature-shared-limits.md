## 주 내용

- DB 한도 저장소 시험의 "창이 끝나면 다시 센다"가 가끔 실패하던 것을 고침
- 두 DB 연결을 시험 전에 미리 열고, 창을 300ms → 1.5초로 늘림

## 상세

**배경**

**변경 범위**

**기술 포인트**
- 원인: 300ms짜리 창으로 "첫 번째는 통과, 두 번째는 막힘"을 보는데, 두 번째 요청이 처음 쓰는 DB 연결(서버 B)이라 연결을 여는 시간이 300ms를 넘으면 창이 이미 끝나 통과돼 버렸다. 저장소 코드가 아니라 시험의 시간 가정이 틀렸다.
