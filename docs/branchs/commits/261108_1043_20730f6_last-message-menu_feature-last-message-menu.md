## 주 내용

- 1:1 대화의 수정·삭제·변경사항 추천을 마지막 대사 한 줄에만 둔다.
- 버튼 상자 대신 말풍선 바로 옆에 점 세 개를 두고, 유저 말은 왼쪽, 상대 말은 오른쪽에 둔다.
- 서버도 마지막 한 줄이 아니면 409를 돌려준다.

## 상세

**배경**
최근 12줄마다 버튼이 붙어, 예시에 적은 위쪽 대사까지 고칠 수 있었다. 사용자는 마지막 말만 고치고, 버튼 상자 대신 점 세 개 메뉴를 원했다.

**변경 범위**
apps/web 대화 화면, apps/api 최근 편집 수, 그 사실을 적는 안내 문서.

**기술 포인트**
화면과 서버가 같은 기준(마지막 1개)을 쓴다. 메뉴는 그 말풍선 옆에서 열리고, 바깥을 누르거나 Esc면 닫힌다.

**안 한 것**
기획 원본, 실측, 커밋 기록은 고치지 않았다. Oracle API 이미지는 다시 올리지 않았다. 월드코퍼챗 화면은 이 메뉴가 없다.

## 결과

**동작 확인**
로컬에서 대사 4줄을 두고 확인했다. 점 세 개 메뉴는 마지막 줄 `오늘 날씨 좋네요.`에만 1개 있었고, 수정·변경사항 추천·삭제가 열렸다. 그 위 줄을 고치는 API는 409였다.

**리스크**
공개 웹은 main 푸시 뒤 Vercel이 받을 수 있다. Oracle API는 아직 최근 12줄을 허용한다. 화면은 마지막 줄만 보여 주므로 그 경로는 화면에서 누르지 않는다.

**후속**
Oracle 이미지를 다시 올리면 서버 제한도 마지막 한 줄이 된다.
