## 상세

**배경**
사용자가 실제 테스트 기반으로 정확하고 빠짐없이 작성하라고 요청했다(2026-11-06). 이 폴더는 비어 있었고 근거는 커밋 기록에 흩어져 있었다.

**변경 범위**

**기술 포인트**
이 폴더는 모델 학습 기록이 아니다. v1은 자체 학습을 하지 않아, 프롬프트와 판정을 실측으로 다듬은 기록을 모았다. 오래된 수치는 커밋 기록의 원문에서 옮기고 날짜를 붙였다. 캐릭터 비밀과 카드 원문은 넣지 않았다.

**안 한 것**
실패 항목을 고치지 않았다. 기준을 낮추지 않았다. 그림 평가와 속도는 이번에 다시 돌리지 않고 2026-11-04 값을 날짜와 함께 적었다.
