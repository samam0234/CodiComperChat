## 주 내용

개발 서버 허용 주소에 같은 망의 192.168.45.220을 더했다.

## 상세

### 배경

기존 허용 주소는 192.168.45.24뿐이라, 다른 기기에서 개발 중인 웹을 열면 Next가 출처를 거절했다.

### 변경 범위

- `apps/web/next.config.ts`의 `allowedDevOrigins`.

### 기술 포인트

개발 서버 전용 설정이다. 운영 배포의 출처 정책은 바꾸지 않는다.

### 안 한 것

운영 서버와 공개 주소는 건드리지 않았다.

## 결과

### 동작 확인

설정 한 줄만 바뀌어 화면 동작은 다시 누르지 않았다.

### 리스크

없다. 개발 서버가 그 사설 주소의 요청을 받는다.

### 후속

develop과 main에 병합한 뒤 푸시한다.

### 관련 문서

- apps/web/next.config.ts
