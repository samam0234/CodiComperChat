## 주 내용

- 대화 명령어: `/다시`(마지막 답 다시 쓰기)·`/계속`(내 말 없이 장면 이어 가기)·`/되돌리기`(마지막 내 말과 답 지우기)·`/상황 내용`(장면 지시)·`/도움말`
- 말 속 표기 `*행동*`(내 행동 묘사)·`(괄호)`(장면 지시)를 모델이 읽도록 추론 규칙 6 추가
- 코레딧(코디컴퍼챗 크레딧): 하루 한 번 출석 무료 1000·프로 5000, 100 코레딧 = 350원, 기록(credit_ledger)
- 프리미엄 모델마다 답 1번 코레딧 값 (Haiku 5.5 5 ~ Fable 5.1 80, Grok 20·25·30), 등급과 상관없이 코레딧으로 쓴다
- 강화 무료(gemma4:12b)는 프로 등급이면 무제한
- 마이페이지 코레딧 카드(잔액·출석·기록), 채팅 모델 칸에 코레딧 값·잔액

## 상세

**배경**
사용자 요청("대화 명령어 필요하다 … 제타나 크랙 혹은 베이비챗에서 공통적으로 쓰이는 명령어", "claude나 grok 모델들은 각 성능마다 포인트값 … 코레딧 … 출석 1000, 프로 5000 … 100당 350원 … gemma4:12b는 프로 사용시 무한")에 따라 만들었다.

**변경 범위**
apps/api(credits 모듈·models·character-chat·conversations·마이그레이션), services/ai(inference 규칙), apps/web(채팅·마이페이지·중계 라우트), e2e

**기술 포인트**
- 명령어는 다른 서비스의 정확한 명령 목록을 확인하지 못해, 캐릭터 채팅에서 흔한 기능(다시 생성·이어 쓰기·되돌리기·지문/OOC 표기)을 한국어 명령으로 만들었다
- 코레딧 차감은 `UPDATE … WHERE credits >= cost RETURNING` 한 문장(동시 요청도 음수 안 됨), 답 실패 시 돌려줌(REFUND 기록)
- 출석은 attendances 기본키(계정×한국 날짜)로 하루 한 번
- /다시는 마지막 내 말 뒤의 답을 모두 지우고 새 답 하나로, /계속은 괄호 장면 지시를 유저 말로 넣어 답만 저장
- 프리미엄을 프로 전용에서 코레딧제로 바꿈 — 출석 코레딧을 무료 등급도 받으므로
- 값: 답 1번 입력 6천·출력 500토큰 원가(1달러 1,450원)를 2배 넘게 덮고 성능 순. Claude 가격은 공개 가격, Grok은 확인 못 해 임시값
- e2e는 MODEL_PREMIUM_FAKE=1로 프리미엄을 가짜 LLM에 보내 코레딧 경로를 시험

**안 한 것**
프리미엄 실제 호출(외부 API)은 보류, 코레딧 판매(결제)도 보류, 운영 콘솔의 코레딧 조정 화면 없음
