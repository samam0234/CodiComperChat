## 주 내용

고객센터에서 로그인한 이용자가 운영자에게 문의를 직접 보내고, 운영 콘솔에서 그 글을 읽고 답할 수 있다. 답변은 고객센터에 다시 보인다.

## 상세

### 배경

고객센터는 이메일 자리표시만 있어 문의가 어디로도 전달되지 않았다.

### 변경 범위

- `support_inquiries` 테이블과 마이그레이션 36.
- 이용자 API `GET·POST /support/inquiries`, 운영자 API `GET /admin/support-inquiries`, `POST /admin/support-inquiries/:id/reply`.
- 고객센터 폼과 내 문의 목록, 콘솔 고객 문의 화면과 대시보드 숫자.
- 자주 묻는 것에서 비밀번호 찾기와 회원 탈퇴가 준비 중이라고 적힌 줄을 지금 동작에 맞췄다.

### 기술 포인트

웹과 콘솔은 Nest만 부른다. 한 사람이 한 시간에 5번, 답이 오기 전에는 10건까지. 비밀번호를 적지 말라고 화면에 적었다.

### 안 한 것

문의 메일은 보내지 않는다. 개인정보 처리방침 문장은 고치지 않았다. 문서와 포트폴리오 숫자 갱신은 다음 커밋이다.

## 결과

### 동작 확인

검증 단위 시험 3건 통과. 로컬 API로 문의를 만들어 목록에 남았고, 고객센터 화면에서 폼으로 한 건을 더 보냈다.

### 리스크

이미 떠 있는 DB에는 마이그레이션 적용이 필요하다. 운영 이미지는 아직 이 표를 모른다.

### 후속

문서와 포트폴리오에 이 기능과 테이블 수를 반영한다.
