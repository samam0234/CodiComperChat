## 주 내용

- 코디포토넷이 대화를 읽는 힘 강화: 등장인물 명단(캐릭터 프로필 성별·나이·직업 + 공방 카드 외형·겉보기 나이 / 내 주인공 프로필 / 이 대화의 지인)·줄거리(지난 이야기·기억)·최근 대화 12턴을 넘김
- "그릴 장면" 고르기: 최근 대사 20개 중 하나를 고르면 그 대사와 앞 3개·뒤 2개를 그림(장면 설명은 비워도 됨)
- LLM은 장면 설계표(인물마다 이름·성별·외모·표정·자세, 장소·행동·빛)만 쓰고 프롬프트는 코드가 조립: 인물 수 태그, 인물마다 (adult woman/man:1.2), 인물 사이 BREAK
- 어린 모습 막기: 어리게 하는 말(child·teen·petite 등) 제거 + 부정 프롬프트 추가, "모두 20살 이상" 규칙
- 만든 뒤 그림에 넣은 사람(예: 유지성(남) · 한서윤(여))을 창에 보여 줌

## 상세

**배경**
사용자 보고("유지성이라는 남성도 등장해야 하는데 … 한서윤은 성인인데 미성년자로 나오는 그림이 나와서 … 캐릭터 페르소나랑 대화내용을 읽어내는 능력을 강화")에 따라 고쳤다. 원인: 태그 단계에 최근 4턴·캐릭터 요약·내 프로필 이름만 넘겼고 인물별 성별·나이·외모가 없었으며, 모델이 태그를 한 줄로 자유롭게 써 사람이 빠지거나 어리게 나왔다.

**변경 범위**
services/ai(photonet·schemas·fake_llm), apps/api(operations: 등장인물 명단·고른 대사), apps/web(photonet 창·character-chat·actions), e2e/tests/operations.spec.ts, docs

**기술 포인트**
- 실제 엔진으로 보고된 상황 재현(남성 캐릭터 유지성 34세 + 27세 여성 주인공 한서윤, 사무실 야근 장면): 처음엔 둘 다 나오고 성인으로 그려졌지만 한서윤에게 유지성의 외모가 옮겨 적힘 → "다른 사람 외모를 옮기지 말고, 외형이 없으면 구별되는 외모를 정하라" 규칙 + 인물 사이 BREAK로 해결, 두 번째 그림에서 외모가 구별됨 (약 40초)
- 성별이 명단에 없으면 소개·외형·호칭·대화에서 추론하게 하고 한국 이름만으로는 판단하지 않게
- 고른 대사는 이 대화(세션)의 것만 받는다(남의 대사 id는 400)
- 닫힌 창에 대사 선택지를 그려 화면에 같은 글이 두 번 생기던 회귀를 e2e에서 발견해, 창이 열렸을 때만 그리게 고침
- WebUI(SDXL)를 켜 둔 채 e2e를 돌리면 RAM 여유가 0.5GB까지 떨어져 시험이 느려지고 실패함 — 시험할 때는 WebUI를 끈다

**안 한 것**
방금 보낸(아직 새로고침 전) 대사는 고르기 목록에 없다(서버 id가 생긴 뒤 보인다). 내 프로필에 성별·외모 칸 따로 두기(지금은 소개 글에서 읽는다)
