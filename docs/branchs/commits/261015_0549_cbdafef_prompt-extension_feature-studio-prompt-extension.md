## 주 내용

- `apps/web/app/studio/[id]/prompt-extend.tsx`: "프롬프트 연장" 버튼 + 프로 등급 안내 상자
- 공방 단계 폼의 긴 글 칸(여러 줄 칸)에만 붙임. 이름·호칭 같은 한 줄 칸은 대상 아님
- 공용 확인 상자 `components/choice-dialog.tsx`의 제목 id를 `useId`로 (여러 개일 때 겹침 수정)
- NAVIGATION_IA, 에이전트 기능 목록

## 상세

**배경**
사용자 지시: 공방에서 글자 수 제한이 있는 칸 중 이름·호칭을 뺀 긴 글 칸은 프로로 바꾸면 3배로 늘릴 수 있다는 식으로, "프롬프트 연장" 버튼을 누르면 [이 기능을 사용하실려면 프로등급으로 전환해야 합니다.] 상자가 떠야 한다.

**변경 범위**
apps/web(공방 폼, 공용 확인 상자), services/ai(assist), docs/plan/NAVIGATION_IA.md

**기술 포인트**
- 결제·등급이 아직 없어 기능 자리만 만들었다. 상자 문구는 사용자가 지정한 그대로 쓰고, 이 칸의 지금 상한과 프로 상한(×3)을 함께 보여 준다. 실제 글자 수 제한(입력칸 maxlength, Nest 검증)은 바꾸지 않았다.
- 대상은 "여러 줄로 쓰는 칸"으로 정했다. 이름·호칭·한 줄 소개·종족/직업 같은 한 줄 칸에는 버튼이 없다.
- 공방 한 화면에 상자가 여러 개 생기면서, 공용 확인 상자의 고정 id(`choice-dialog-title`)가 겹치는 문제가 드러나 `useId`로 고쳤다.

**안 한 것**
- 프로 등급·결제·실제 상한 늘리기, 엑스트라 칸의 연장

## 결과

**동작 확인**
- 브라우저(web 3000 → api 4000) 10개 통과:
  - 정체성 단계 버튼 없음, 성격·말투 단계는 성격 요약에만(호칭 규칙 없음), 캠페인 역할 6칸 모두
  - 누르면 지정 문구 상자, "400자 → 1,200자" 안내, 확인·Esc로 닫힘
  - 글자 수 제한은 그대로(maxlength 400), 390px 가로 스크롤 없음, 오류 없음
- web `tsc --noEmit`
