## 주 내용

- 기본 Gemma 4 e4b의 첫 답과 다음 답 출력 예산을 줄이고 고정 지시문의 중복 문장을 정리했다.
- 현재 대화·최근 메시지·관계·요약을 준비 캐시에서 갱신하고 이전 세션 요약을 전달한다.
- 삭제된 기억의 벡터 검색 결과를 현재 DB 기억과 대조한다.
- 독립적인 맥락 조회를 병렬 처리하고 실제 모델 지연·기억 회상 평가 도구를 추가했다.

## 상세

**배경**

사용자가 웹의 기본 모델 지연을 줄이고 첫 답 60초, 다음 답 완료 30초를 목표로 요청했다.

**변경 범위**

Nest 대화 준비·기억 검색, FastAPI 추론 프롬프트·출력 예산, 회귀 시험과 실측 문서를 갱신했다.

**기술 포인트**

기본 일반 대화의 출력 상한은 첫 답 192토큰, 이후 96토큰이다. 캐릭터 설정·최근 대화·요약·검색된 기억을 전달하며 매 요청의 대화 상태를 다시 확인한다. 첫 요청의 대화 없음 상태가 다음 요청까지 재사용되는 문제를 수정했다. 계약 시험의 가짜 모델 환경변수는 해당 시험 클래스 동안만 적용한다.

**안 한 것**

운영 서버의 기본 공개키 인증이 거절되어 운영 배포와 웹 경로의 시간 검증은 후속으로 남았다.

## 결과

**동작 확인**

API 타입 검사·변경 파일 린트·단위 시험 통과. AI 규칙 시험과 실제 모델 평가의 세부 결과는 테스트 정본과 대화 지연 실측 문서를 따른다. 로컬 GPU 예열 상태의 세 질문을 세 번 실행하여 완료 시간이 2.625~4.657초였다. 회상 질문은 금요일·오후 3시·수선화 서점·보리를 모두 포함했다. 출력 상한에 잘린 표본은 없었다.

**리스크**

로컬 GPU 결과로 운영 CPU의 목표 달성을 판단할 수 없다. 수정 후 모델 비적재 상태의 첫 답과 긴 대화 전체의 정확도는 추가 측정이 필요하다.

**후속**

서버용 SSH 별칭 또는 키 파일 경로를 확인한 뒤 배포와 운영 웹 경로 측정을 진행한다.
