## 주 내용

- 마이페이지를 가운데 정렬한 한 단(최대 960px)으로 다시 짜고 위에서부터 프로필 머리말(첫 글자 아바타·인증·등급·가입일 배지) → 바로가기 3개 → 코레딧·요금 등급 카드 → 결제 내역 → 내 프로필 캐릭터 순으로 배치
- 요금 등급 카드: 등급별 혜택(공방 긴 글 칸·강화 무료 모델·출석 코레딧) 표시
- 내 프로필 캐릭터를 카드 격자(아바타·이름·소개 2줄·수정/삭제)로 바꾸고 새로 만들기 카드 추가
- 설정을 두 단(왼쪽 목차 + 오른쪽 카드)으로: 화면(테마 미리보기 카드) · 계정(개요·이메일 인증 상태·이름 수정) · 비밀번호 · 로그인 · 알림·수위(준비 중) · 정책·도움말 · 회원 탈퇴
- 좁은 화면에서는 목차가 가로 칩 줄로, 카드는 한 단으로

## 상세

**배경**
사용자 요청("마이페이지 페이지는 업그레이드 시켜서 좀 더 보기 좋게 … 너무 왼쪽으로 치우친 것 같고 프로필도 그리고 설정 페이지도 부실한 것 같은데")에 따라 고쳤다. 원인은 본문 폭(1160px)은 넓은데 각 블록이 max-width 560px로 왼쪽에 붙어 있던 것이다.

**변경 범위**
apps/web/app/me/*, apps/web/app/settings/*, e2e/tests/mypage.spec.ts

**기술 포인트**
- 기존 e2e가 기대는 문구((미인증), 프로 (공방 긴 글 칸 3배), 기간 늘리기, 영역 이름 결제 내역·회원 탈퇴, 로그아웃 버튼 하나)는 그대로 지킴
- 테마 라디오는 눈에서 숨기고 카드로 보이게(:has(input:checked)로 선택 표시), 키보드 포커스 링 유지
- 색은 기존 디자인 토큰만 사용, 라이트·다크·모바일을 스크린샷으로 확인
- 비밀번호 변경 시 다른 기기 로그인이 풀린다는 안내는 sessionVersion 증가 동작과 일치함을 코드로 확인

**안 한 것**
표시 이름·이메일을 마이페이지에서 바로 고치는 입력(설정에서만 수정), 프로필 사진 업로드, 알림·수위 설정 기능 자체(준비 중 표시만)
