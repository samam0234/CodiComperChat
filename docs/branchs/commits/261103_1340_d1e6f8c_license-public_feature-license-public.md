## 주 내용

- 공개는 배포를 위한 것이고 허락이 아니라고 라이선스에 적었다
- 허락 없는 clone·다운로드·미러링·실행·호스팅과 기계 학습 사용을 금지했다
- 권리자가 쓰는 배포 시스템의 clone은 허용했다
- GitHub 약관이 공개 저장소에 요구하는 범위(보기, GitHub 안 포크)는 예외로 적었다
- README에 안내를 넣었다

**기술 포인트**
공개 저장소는 기술적으로 clone을 막을 수 없다. GitHub 약관상 공개 저장소에는 보기와 포크 권한이 따른다. 그래서 이 조항은 법적 제한이며, 기술적으로 막으려면 저장소를 비공개로 돌려야 한다.

**안 한 것**
저장소 공개 설정 변경, 권리자 이름 채우기(사용자가 정하지 않았다). 법률 검토.
