## 주 내용

공식 캐릭터 이세연의 초상을 사용자가 준 새 그림으로 바꿨다.

## 상세

### 배경

초상은 DB에 저장되고, 시드는 초상이 비어 있을 때만 넣는다. 파일만 바꾸면 이미 시드된 DB에는 옛 그림이 남는다.

### 변경 범위

- `lee-seyeon.webp`: 사용자 그림(784px JPG)을 512px WebP(약 35KB)로 교체. 기존과 같은 정사각 512px.
- `seed.mjs`: 이세연만 DB 초상이 파일과 다르면 파일로 맞춘다. 유지성은 그대로.
- `CHARACTERS.md`: 초상 교체 기록.

### 기술 포인트

바이트를 비교해 같으면 쓰지 않으므로 시드를 여러 번 돌려도 안전하다. 운영자가 콘솔에서 바꾼 이세연 초상은 다음 시드 때 이 파일로 되돌아간다(사용자 지시에 따른 선택).

### 안 한 것

그림 속 명찰이 "김서연 비서실"이라 카드 이름(이세연)과 다르다. 그림은 그대로 썼다. 서버·개발 DB에 시드는 돌리지 않았다.

## 결과

### 동작 확인

시드 문법 검사(node --check) 통과. DB에 적용해 화면에서 보는 확인은 하지 않았다.

### 리스크

운영자가 바꾼 이세연 초상이 시드 때 덮인다.

### 후속

서버·개발 DB에서 `npx prisma db seed`.
