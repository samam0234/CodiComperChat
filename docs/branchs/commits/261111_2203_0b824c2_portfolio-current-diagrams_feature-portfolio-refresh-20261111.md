## 주 내용

- 예전 DB 수가 적힌 구조도 대신 11월 11일 프레임워크 이미지를 사용한다.
- 백엔드 상세의 오래된 데이터 지도 노출을 정리하고 사이트·Word·PDF·발표자료를 다시 생성했다.
- 기존 캡처 파일은 보존했다.

## 상세

**배경**
렌더링에서 오래된 구조도에 테이블 28개가 적혀 있는 것을 확인했다. 현재 38개와 혼동되지 않게 최신 설명용 도식으로 연결했다.

**변경 범위**
포트폴리오 콘텐츠 정본·복사본·문서와 생성기.

**기술 포인트**
기존 제품 캡처를 편집하지 않고 최신 정본 도식과 날짜를 표시한다.

**안 한 것**
제품 코드·기획 원본·보관된 과거 이미지 파일은 수정하지 않았다.

## 결과

**동작 확인**
정적 12페이지 빌드와 동기화 검증 통과. Word·PDF·발표자료를 다시 생성하고 바뀐 도식 배치를 렌더링해 확인했다.

**리스크**
브라우저 상호작용 검증은 컴퓨터 사용 도구의 URL 확인 실패로 수행하지 못했다.

**후속**
요청받은 병합·푸시 및 Vercel 정적 재배포.
