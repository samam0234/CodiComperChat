## 주 내용

사용자별 기억과 공통 말투 자료를 ChromaDB에 로컬 해시 임베딩으로 저장하고, 이번 말과 가까운 조각만 대화 프롬프트에 넣는다.

## 상세

### 배경

기억은 글자 검색으로 고르고 있었고, 벡터 저장소는 없었다. 가중치 학습은 추론을 더 느리게 하고 기획서의 v1 범위도 아니다.

### 변경 범위

- 공통 말투 JSON과 사용자별 기억을 ChromaDB에 넣는다. 다른 사용자의 기억은 검색되지 않는다.
- 임베딩은 한국어 2-gram 해시다. 추론 모델을 부르지 않는다.
- 벡터가 기억을 고르면 그 조각과 직접 적은 기억만 남긴다. 저장소를 열지 못하면 글자 검색으로 돌아간다.
- 길이 분포를 보는 전처리가 있다. 분류 모델을 따로 학습하지는 않는다.

### 기술 포인트

웹은 FastAPI를 부르지 않는다. Nest가 짧은 조회로 `/rag/query`를 보고, 대기열 밖에 둔다.

### 안 한 것

모델 가중치 학습, EDA 노트북, 신경망 임베딩 다운로드. 포트폴리오 docx·pdf·pptx는 생성 스크립트가 슬라이드 도구를 찾지 못해 다시 만들지 않았다.

## 결과

공개 API는 이 경로를 아직 모른다. 해시 임베딩은 의미가 먼 문장을 놓칠 수 있다.
