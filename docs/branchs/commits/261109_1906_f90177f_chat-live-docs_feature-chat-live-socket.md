## 상세

### 배경

직전 문서는 제품에 웹소켓이 없다고 적혀 있었다. 화면 전달을 넣은 뒤 그 문장이 틀려졌다.

### 변경 범위

- 기획서 0.1.4 구현 메모. 원래 스트리밍 요구 문장은 지우지 않았다.
- 처리 순서, 구조, 인수인계, 기능 목록, API, 현황, 할 일 D01.
- 포트폴리오 정본을 고친 뒤 시트·지식 자료와 Word·PDF·슬라이드를 다시 만들었다.

### 안 한 것

운영 서버는 다시 올리지 않았다. 월드 플레이 토큰 전달은 하지 않았다.
