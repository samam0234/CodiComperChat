## 주 내용

2026-11-11 대화 속도·호스팅 오류 고침이 일부 문서에만 적혀 있던 것을 살아있는 문서 전반에 맞췄다.

## 상세

### 배경

고침 직후 문서는 실측 문서·디버깅 일지·배포 절차·인수인계에만 있었다. 환경변수 문서와 배포 안내에는 새 설정이 없었고, "키 오류(401)는 덮지 않는다"는 문장이 지금 동작과 어긋났다. 시험 수도 옛 값이었다.

### 변경 범위

- `environment.md`, `deploy-guide.html`: 새 설정 5개(연결·조각 사이·전체 시간 제한, 예비 대사 수·토큰 상한), JSON 호출 시간 제한의 뜻, 키·접근 오류 예비.
- `API_DOCUMENTATION.md`: `/infer/stream`에 호스팅 조각도 나옴, `X-AI-Priority` 머리글.
- `FEATURES.md`: 시험 파일과 2026-11-11 변경(서버에는 아직 없음).
- `TESTING.md`: API 249개(파일 37), AI 92개.
- `oracle-deploy-latency.md`: 키·접근 오류 예비를 같은 날 두 번째 고침으로.
- `TASKS.md`: e2e 실패 3개를 Q09~Q11로.

### 기술 포인트

고칠 문자열이 정확히 하나가 아니면 멈추는 스크립트로 한꺼번에 바꿨다. 기록용 문서(커밋 기록·디버깅 일지·실측 노트의 과거 문장)는 그대로 두었다.

### 안 한 것

e2e 실패 3개는 고치지 않았다. 포트폴리오 지식 스냅샷은 생성물이라 다시 만들지 않았다. e2e 개수(123)는 이번에 돌린 값(119개 중 116 통과)과 달라 보이나 이유를 확인하지 못해 고치지 않았다.
