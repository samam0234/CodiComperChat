## 주 내용

- 코디포토넷 창 맨 위 수위 토글: 전체 이용가(기본, 창을 열 때마다 이것으로) / 19 성인. 성인 모드는 경고 띠·빨간 테두리·실사풍 잠김, 갤러리는 모드별로 따로(성인 그림에 19 표시)
- 성인 확인(임시): POST·DELETE /auth/me/adult — 이메일 인증 + 생년월일 만 19세(한국 시각) + 동의. 생년월일은 처음 넣은 것으로 고정, 응답에는 adult 하나만(생년월일은 내보내지 않음). 설정 → 콘텐츠 수위에서 확인·끄기
- 전체 이용가: 노출·성적 묘사·수영복·유혈·부상·무기·폭력·공포를 설계 규칙·태그 지우기·부정 프롬프트·그림 검수 네 곳에서 뺌
- 성인: 성인끼리 합의한 성적 장면·폭력 허용, 인물은 mature adult·adult body로 못 박고 수위 태그(safe·sensitive·nsfw·explicit)는 설계표가 장면에 맞게 고름. 실사풍은 Nest·services/ai 두 곳에서 막음
- 어느 모드든 막는 것: 어려 보이는 인물, 강제·의식 없는 상대·묶임·성과 폭력의 결합, 실존 인물, 동물, 자해, 혐오. 코디포토넷 전용 그림 검수(photonet_moderation) — 성인 모드는 확실하지 않거나 판정을 못 하면 막고 코레딧 환불
- 서버가 매번 DB에서 성인 확인을 다시 봄: 동의를 거두면 성인 그림은 목록·본문에서 곧바로 사라지고(404) 성인 모드 만들기는 403

## 상세

**배경**
사용자 요청("sfw가 디폴트이고 nsfw는 버튼 클릭해서 바꿀 수 있고 … 전체이용가 버전, 성인버전 따로 만들어 냈으면 해"). 사용자 결정: 성인 확인은 임시로 생년월일+동의(+이메일 인증), 성인 모드는 성행위 묘사까지, 실사풍은 성인 모드에서 막기.

**변경 범위**
apps/api(account: 성인 확인, auth: adult 응답, operations: rating, prisma: users.birthDate·adultConsentAt, photonet_images.rating), services/ai(photonet·photonet_moderation·image_engine·schemas), apps/web(설정 콘텐츠 수위, 코디포토넷 창), e2e, docs

**기술 포인트**
- 마이그레이션 20261024120000_photonet_rating (열 추가만, 기존 그림은 sfw) — 개발 DB에 적용함
- 만 19세 미만으로 막힌 뒤 날짜만 고쳐 다시 시도하는 것을 막으려고 생년월일은 처음 값으로 고정(동의만 거둘 수 있음)
- 전체 이용가 태그 정리는 성인용 금지어 목록까지 함께 적용(더 엄격한 쪽)
- 실제 엔진(골목 싸움 장면): 전체 이용가 설계표는 칼·피 없이 막아서는 장면으로 바뀜. 성인 모드는 두 사람 모두 뚜렷한 성인으로 그려짐, 한 번은 검수 통과·한 번은 검수가 막아 환불 — 성인 검수는 일부러 엄격
- 검수 단계로 올라온 gemma4가 그래픽 메모리에 남아 있으면 그리기만 따로 할 때 SDXL이 290초를 넘김(설계 단계가 있는 정상 흐름에서는 내린다)

**안 한 것**
본인인증(PASS 등)으로 바꾸기 — 공개 전 필수(청소년보호법: 나이 확인·19 표시·청소년 접근 차단). 운영 콘솔에서 성인 그림 신고·검토
