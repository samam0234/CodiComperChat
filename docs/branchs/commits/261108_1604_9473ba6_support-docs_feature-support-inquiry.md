## 주 내용

고객센터 문의와 지금 스키마(테이블 38개, 마이그레이션 36개)를 살아있는 문서와 포트폴리오에 맞췄다. 기본 모델은 gemma4:e4b, 강화는 gemma-4-31b-it로 적었다.

## 상세

### 배경

문의 기능이 들어갔는데 문서와 포트폴리오는 문의가 없고, 표 수와 모델 설명이 그 전 상태였다. 스프레드시트 제목에는 이 저장소에 없는 이름이 있었다.

### 변경 범위

- 기능 목록, API 문서, 인수인계, 현황, 데이터베이스, 스택, 아키텍처, 루트 안내.
- ERD 계정 그림에 support_inquiries를 넣고, 생성기 그룹에도 넣었다. 2026-11-07 검증 문장은 그대로 두고 이날 표를 덧붙였다.
- 포트폴리오 정본과 스프레드시트를 고친 뒤 시트·ERD·지식 자료와 Word·PDF·슬라이드를 다시 만들었다.

### 기술 포인트

지식 스냅샷은 손으로 고치지 않고 생성기로 다시 만들었다. Nest 경로 155는 2026-11-07 대조로 남기고, 문의 5경로를 더했다고만 적었다.

### 안 한 것

기획 원본은 고치지 않았다. 운영 서버를 다시 올리지 않았다. 데이터 지도 그림 파일은 37개일 때의 그림으로 두었다.

## 결과

### 동작 확인

생성기가 ERD 테이블 38, 관계 41, 시트 9, 지식 문서 24를 냈다. 포트폴리오 문서 세 가지가 다시 만들어졌다.

### 리스크

공개 포트폴리오 사이트는 이 푸시만으로 다시 배포되지 않는다. 공개 API는 문의 표를 아직 모른다.

### 후속
