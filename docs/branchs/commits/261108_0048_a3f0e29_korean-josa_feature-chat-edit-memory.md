## 주 내용

- 은/는·이/가·을/를를 받침에 맞게 붙이는 조사를 API·웹·AI에 두었다.
- 화면과 프롬프트에 나가던 `이(가)`, `은(는)`, `을(를)`를 그 함수로 바꿨다.
- 모델 답에 괄호 조사가 남아 있으면 저장·표시 전에 고친다.
- 1:1 답은 방금 한 말에 먼저 반응하고, 기억은 지금 말과 맞을 때만 말하도록 지시했다. 출력 상한은 1200에서 800토큰이다.

## 상세

**배경**
모델과 서버 문장이 `[이름]이(가)`처럼 조사를 괄호로 남겨 어색했다. 답도 길게 늘어져 체감이 느렸다.

**변경 범위**
`apps/api`의 조사 함수와 이용자에게 보이는 문장, `apps/web`의 표시 교정, `services/ai`의 답 후처리·요약·검수 문장·대화 지시.

**기술 포인트**
한글 음절의 받침(ㄹ 받침은 `로`)으로 고른다. 모델 평가는 다시 돌리지 않았고, 지시는 장면 형식 규칙보다 앞에 두어 나레이션 형식은 끝이 이긴다.

**안 한 것**
기획 원본은 수정하지 않았다. 출력 시간 제한은 늘리지 않았다. 스트리밍으로 화면을 먼저 채우는 경로는 넣지 않았다.
