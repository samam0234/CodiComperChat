## 주 내용

- 1:1 대화의 최근 12줄은 수정·삭제할 수 있다.
- 수정과 삭제 사이에 변경사항 추천을 두어, 적은 방향으로 그 줄만 다시 쓴다.
- 기억 화면에서 직접 적을 수 있고, 직접 적은 기억은 매 턴 불러 온다. 말은 지금 상황과 맞을 때만 한다.
- 유저가 자기 프로필이나 상대 설정을 말한 턴은 뒤에서 장기 기억으로 남긴다.
- 때와 곳은 1:1 대화와 세계관 플레이에 보이고, 시간·장소 단서가 있을 때만 바뀐다.

## 상세

**배경**
최근 대사를 고치거나 지울 수 없었고, 기억은 자동 정리와 삭제만 있었다. 장면의 때와 곳도 화면에 없었다.

**변경 범위**
Prisma 마이그레이션 `20261108123000_chat_memory_scene`, `apps/api` 대화·기억·세계관, `apps/web` 대화·기억 화면, `services/ai` `/rewrite-line`·`/notice-facts`.

**기술 포인트**
웹은 Nest만 부른다. 방향 다시 쓰기는 그 대화의 모델 횟수·코레딧을 쓴다. 자동 사실 기억은 답 뒤에 돌아 답 속도를 늘리지 않는다. 직접 적은 기억은 최대 12개까지 항상 넣고, 자동 기억은 많으면 이번 말과 관련된 것만 고른다.

**안 한 것**
세계관 플레이의 대사 수정·삭제는 넣지 않았다. 스트리밍은 넣지 않았다. 기획 원본은 수정하지 않았다.

## 결과

**동작 확인**
API vitest 241개, AI unittest 73개, API·웹 타입 검사를 통과했다. 브라우저에서 수정·기억 입력을 눌러 보지는 못했다.

**리스크**
이미 떠 있는 DB는 마이그레이션을 적용해야 한다. 적용 전에는 때·곳 칸과 직접 기억이 실패한다. 운영 API는 이미지를 다시 올려 기동할 때 마이그레이션이 적용된다.

**후속**
운영 VM의 API를 다시 띄운 뒤 대화 화면에서 수정·기억·때와 곳을 확인한다.
