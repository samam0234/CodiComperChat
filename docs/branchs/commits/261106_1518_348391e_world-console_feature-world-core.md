## 상세

**배경**
사용자 요청(2026-11-06): 운영자 페이지에 새 기능을 오차 없이, 관리하기 좋게. 필요하면 직접 접근 기능도.

**변경 범위**
`console/app/worlds/**`(목록·[id]·review·events·settings, world-actions·world-tabs·stats-row), `console/app/api/worlds/**`(운영자 그림 중계), `console/app/actions/admin.ts`, `console/lib/worlds.ts`, `console/components/sidebar.tsx`, `console/app/page.tsx`, `e2e/tests/worlds.spec.ts`.

**기술 포인트**
운영자는 비공개·발행 전·내려간 세계관과 검수 대기·막힌 그림까지 본다. 파트 목표(이용자에게는 숨김)도 보여 준다. 내리기는 사유가 필수이고 만든 사람에게 보인다. 그림은 통과·거절·막기·막기 풀기, 지도는 통과·거절·지우기. "웹에서 열기"로 이용자 화면을 바로 연다. 운영 설정(하루 보상 횟수·이벤트 확률·최소 간격)은 Nest가 범위를 검사한다. 플레이 대화 내용은 콘솔에 보이지 않는다(개인정보).

**안 한 것**
플레이 대화 열람, 이벤트 보상 되돌리기(코레딧 조정은 기존 계정 화면 몫).
