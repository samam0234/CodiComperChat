## 주 내용

- 내 말풍선의 그라데이션을 빼고 상대 말풍선과 같은 면 색·테두리로 맞췄다.
- 모델 안내 글은 줄높이와 안쪽 여백을 늘려 둥근 모서리에 글자가 닿지 않게 했다.
- 모델 선택 칸 높이를 40px로 올려 글자가 칸 안에 들어가게 했다.
- 좁은 화면의 대화 칸은 `dvh`로 높이를 잡는다.

## 상세

**배경**
내 말풍선이 그라데이션에 흰 글자라 읽기 어려웠다. CSS 모듈 `.modelNote`(빌드 뒤 `zqH-Va_modelNote`)는 둥근 대화 칸에 잘렸다.

**변경 범위**
`apps/web`의 1:1 대화, 세계관 플레이, 메시지, 에이전트, 공방 시험, 홈 예시 말풍선.

**기술 포인트**
메신저 모드의 노란 말풍선은 글자가 검게 보여 그대로 두었다. 보내기 단추의 그라데이션은 말풍선이 아니라 그대로다.

**안 한 것**
대화 내용·API는 이 커밋에서 바꾸지 않았다.

## 결과

**동작 확인**
웹 타입 검사는 앞선 변경과 함께 통과했다. 브라우저에서 말풍선을 눌러 보지는 못했다.

**리스크**
내 말과 상대 말이 색만으로는 덜 구분된다. 위치(오른쪽/왼쪽)와 모서리 방향으로 구분한다.

**후속**
화면에서 모델 안내와 말풍선 대비를 한 번 본다.
