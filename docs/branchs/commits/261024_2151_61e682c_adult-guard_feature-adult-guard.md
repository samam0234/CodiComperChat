## 주 내용

- 성인 모드: 등장인물 명단·장면 설명·고른 대사에 미성년자 관련 설정(초·중·고등학생, 고1~3, 교복, 미성년, 소년·소녀, 19세 미만 나이 등)이 있으면 그리기 전에 400(코레딧 환불)
- 성인 모드: 실사 계열 부정 프롬프트(photorealistic·photo·3d render 등)와 2d·illustration 태그, 그림 검수에 realistic 항목 추가
- 실존 인물 항목은 성인 모드에서만 막음 — 전체 이용가 실사풍이 늘 막히던 문제 해결
- 성인 확인 동의 문구와 이용약관에 거짓 생년월일 입력의 법적 책임은 이용자에게 있음을 명시(스팀식)

## 상세

**배경**
사용자 요청("성인용 이미지 제작 시 미성년자 관련 출연 금지, 실사 및 실사에 90% 가까운 이미지 엄격히 금지", "본인인증은 이대로 두고 거짓 정보 법적 책임은 유저에게").

**변경 범위**
services/ai(photonet, photonet_moderation, image_engine), apps/web(약관, 성인 확인 문구), e2e/tests/operations.spec.ts, docs/plan/OPERATIONS.md

**기술 포인트**
- 실제 엔진·gemma 검수 실측(성인 모드 규칙): 실사 사진풍 → 막음(realistic·real_person), 실사에 가까운 3D풍 → 막음(realistic), 애니 성인·수채화 성인 → 통과, 비성적 어린이 그림 → 막음(young)
- 같은 실측에서 전체 이용가 실사풍이 real_person으로 막히는 기존 문제 발견 → 성인 모드에만 적용
- 미성년자 낱말은 넓게 잡되 "학생"·"대학생"·"대학교 1학년"·"아기자기"·"18세기"는 걸지 않게 다듬음(사례 15개 확인)
- 동의 문구에 "생년월일"이 들어가 e2e의 라벨 찾기가 두 개를 잡음 → 입력칸 이름으로 찾게 고침. 미성년자 시험은 요청 한도(10분 6번) 때문에 따로 분리

**안 한 것**
성인 콘텐츠 운영 체계(신고·검토)는 사용자가 비워 둠
