## 주 내용

- 기본 대화의 첫 글자를 즉시 표시하고 수신 조각을 프레임에 맞춰 이어서 표시한다.
- 교정·완료 신호에서 대기 글자를 정리하고 완료 때 저장된 답을 적용한다.
- Nest에서 스트림의 UTF-8 문자를 전송 조각 경계에 걸쳐 복원한다.

## 상세

**배경**

생성 중에 글자를 보여 달라는 사용자 요청이다. 기존 모델·소켓의 토큰 전달 경로에 브라우저의 점진 표시를 적용했다.

**변경 범위**

웹 대화 UI·live-text 표시기, Nest AI 스트림 수신기와 회귀 시험, 데이터 흐름 문서.

**기술 포인트**

첫 글자는 바로 표시한다. 큰 조각은 프레임마다 나누고 대기량에 맞춰 따라잡는다. done 신호는 대기 표시를 즉시 완료한다. replace·오류에서 이전 예약 표시를 취소한다. 한글이 TCP 바이트 경계에서 나뉘어도 Node UTF-8 스트림 디코더가 복원한다.

## 결과

**동작 확인**

웹 표시기 시험 3개와 AI 클라이언트 시험 8개 통과. 웹·API 타입 검사와 변경 파일 린트 통과. 첫 글자·완료·교정·취소와 분할된 한글 바이트를 확인했다.

**리스크와 후속**

운영 서버 배포와 로그인한 웹에서 실측이 필요하다. 모델의 첫 토큰 생성 전 대기 시간은 별도 측정 대상이다.
