## 상세

**배경**
사용자가 다음 작업을 Cursor에게 맡기기로 했다. 지금까지의 약속 일부는 Claude 쪽 기록에만 있어 다른 도구는 볼 수 없었다.

**변경 범위**
`docs/TASKS.md`(신규), `.agents/`, `.cursor/`, `.claude/`, `.codex/`, `.grok/`, `.antigravity/`, 루트 `AGENTS.md`, `docs/README.md`, `docs/AGENT_HANDOVER.md`, 브랜치·커밋 가이드.

**기술 포인트**
할 일은 `TASKS.md` 한곳에서만 관리한다. 인수인계의 기능 후속 목록을 옮겼다. 브랜치 문서 곳곳의 "병합한 뒤 푸시" 예시는 합의와 달라 고쳤다. `apps/web/AGENTS.md`는 "변경분을 커밋한다"에서 "되돌린다"로 고쳐 실제 작업 방식에 맞췄다.

**안 한 것**
코드 변경, 병합, 푸시. `main` 병합 방식은 정하지 않고 사용자에게 물을 항목으로 남겼다(D10).

## 결과

**동작 확인**
문서 안 상대 링크를 스크립트로 전부 확인했다. Cursor가 규칙을 실제로 불러오는지는 확인하지 못했다.

**리스크**
`TASKS.md`의 작업별 우선순위는 내 판단이다.

**후속**
Cursor가 T01부터 진행한다. 개발 서버를 먼저 꺼야 한다.
