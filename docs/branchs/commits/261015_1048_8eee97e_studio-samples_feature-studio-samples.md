## 주 내용

- `POST /studio/characters/:id/samples`: 같은 질문 "지금 뭐 해?"에 지금 카드로 답 2개, 아무것도 저장하지 않음
- 웹: 성격·말투 단계 맨 아래 "말투 샘플" 영역 (`sample-replies.tsx`)
- API 문서·NAVIGATION_IA

## 상세

**배경**
기획서 §6.2 "성격·말투 … 같은 질문 '지금 뭐 해?'에 대한 샘플 답 2개를 즉시 보여 말투를 검증한다". 지금까지는 3턴 테스트와 빠른 질문 칩으로 대신했다.

**변경 범위**
apps/api(studio), apps/web(공방 폼·서버 액션), docs

**기술 포인트**
- 3턴 테스트와 같은 경로(카드 → 페르소나 지식 → 검색 → 조립 → 개인사 가드)로 답하므로 샘플의 말투가 실제 대화와 같다.
- 저장하지 않는다: 테스트 턴을 쓰지 않고, 테스트 상태(카드 지문)를 건드리지 않는다. 카드를 고치며 여러 번 눌러도 3턴 테스트에 영향이 없다.
- 서버가 저장된 카드로 답하므로, 버튼을 누르면 먼저 저장을 끝낸다.
- 첫 메시지가 아직 없는 단계(성격·말투는 첫인사보다 앞)에서도 동작하도록 이름·반말/존댓말만 필수로 했다.

**안 한 것**
- 샘플 질문 바꾸기(고정 질문 1개), 샘플 비교 기록

## 결과

**동작 확인**
- 브라우저(임시 서버 + 실제 Ollama) 8개 통과:
  - 말투 전에는 버튼 꺼짐 + 안내, 정하면 켜짐
  - 질문 1개 + 답 2개가 표시됨(예: "손님께서는요, 저는 오늘 아침에 막 꽃을 물에 담가두고…")
  - 누르면 카드가 먼저 저장됨, 3턴 테스트 0/3 유지, 버튼이 "다시 보기"로 바뀜
  - 390px 가로 스크롤 없음, 오류 없음
- 단위 테스트 75개, `typecheck:api`, web `tsc --noEmit`

**리스크**
샘플은 호출이 2번이라 소형 모델에서 10~20초 걸릴 수 있다(버튼에 "만드는 중…" 표시).
