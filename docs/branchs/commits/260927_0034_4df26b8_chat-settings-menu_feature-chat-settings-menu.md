## 주 내용

- `chat-menu.tsx` 신규: 대화 상자 오른쪽 위 "⋮" 버튼과 메뉴(대화 목록 · 메모리 기록 확인 · 캐릭터 내 상태설정)
- 키보드 메뉴 동작(↓ 열기, ↑↓·Home·End, Esc 닫기 후 버튼으로 초점, 바깥 클릭 닫기, 열면 첫 항목에 초점)
- 메뉴 버튼 아래로 첫 말풍선이 겹치지 않게 대화 기록 위쪽 여백 52px
- 입력창 안내 문구를 한 줄로 고정(좁은 화면에서 두 줄로 접혀 잘리던 문제)하고 문구를 짧게 줄임

## 상세

**배경**
사용자가 대화 상자(`character-chat-module__…__log`) 오른쪽 위에 점 3개로 "캐릭터 대화 내 전용 설정"이 나타나고, 그 안에 대화 목록·메모리 기록 확인·캐릭터 내 상태설정이 있기를 요청했다. 앞 세 브랜치가 각 페이지를 만들었고, 이 브랜치가 입구를 붙인다.

**변경 범위**
apps/web(채팅 메뉴 컴포넌트, 채팅 화면·스타일, 공용 입력창 스타일), `docs/plan/NAVIGATION_IA.md`

**기술 포인트**
- 메뉴는 대화 기록(`.log`) 안이 아니라 대화 상자(`.chat`)에 절대 위치로 둔다. 기록이 스크롤돼도 버튼은 제자리에 있다.
- WAI-ARIA 메뉴 패턴(`aria-haspopup`, `aria-expanded`, `role=menu/menuitem`)을 따랐다.
- 입력창 안내 문구 결함은 앞선 줄바꿈 작업에서 생긴 것이다. 텍스트를 줄여도 320px에서는 입력칸 폭이 86px뿐이라 해결되지 않아, 안내 문구를 한 줄로 두고 넘치면 잘리게 했다.

**안 한 것**
- 메뉴 항목 추가(대화 초기화·삭제 등)

## 결과

**동작 확인**
실제 Chrome(390px)으로 앞 세 브랜치까지 포함한 전체 흐름 22개 통과: 빈 대화 목록 안내, 메뉴 버튼 위치(상자 오른쪽 위에서 11px), 메뉴 항목 3개, 첫 항목 초점, ↓ 이동, Esc로 닫고 버튼 초점 복귀, 바깥 클릭 닫기, 새로고침 후 대화가 이어서 보임(내 말 3, 캐릭터 4), 프로필 이름 유지, 열면 맨 아래로 스크롤, 3번 오간 뒤 기억 3개 자동 생성, 기억 지우기, 상태설정 기본값·카드 호칭 안내, 슬라이더 구간 이름 변화, 저장 값 유지, 설정 후 답에 호칭 "서윤아" 등장, 대화 목록 카드와 이동, 비로그인은 메모리·상태설정 페이지에서 로그인으로. 콘솔 오류 없음. 320px·390px에서 입력창 한 줄 높이 유지, 가로 스크롤 없음. 웹 `tsc`와 프로덕션 빌드 통과.

**리스크**
320px에서는 안내 문구 끝이 잘려 보인다(한 줄 유지).
