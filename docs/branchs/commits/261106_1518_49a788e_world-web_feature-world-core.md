## 주 내용

- 이용자 사이트에 월드코퍼챗 화면을 더했다: 목록(`/worlds`), 소개(`/worlds/[id]`), 편집기(`/worlds/[id]/edit`), 플레이(`/worlds/[id]/play`)
- 대화 방식 4가지(기본 채팅·비주얼노벨·소설·메신저)를 화면마다 다르게 그린다
- 코퍼맵(지도 위 장소 핀과 지금 있는 인물), 이벤트 미니게임 5종(사다리·주사위·볼링·제비뽑기·미로) 창을 더했다
- 헤더와 서랍 메뉴에 "월드"를 더했다

## 상세

**배경**
사용자 요청(2026-11-06) 월드코퍼챗의 화면.

**변경 범위**
`apps/web/app/worlds/**`, `apps/web/app/api/worlds/[...path]/route.ts`(Nest `/worlds/*` 중계), `apps/web/lib/worlds.ts`·`world-types.ts`, `components/site-header.tsx`·`site-drawer.tsx`. 플레이 상태에 `hasMap`을 넣느라 `apps/api/src/worlds/world-play.service.ts`도 조금 고쳤다.

**기술 포인트**
브라우저는 FastAPI를 부르지 않고 Next 중계 → Nest로만 간다. 중계는 경로 조각을 다시 인코딩해 `..`로 다른 Nest 경로에 닿지 못하게 한다. 그림은 올리기 전에 브라우저에서 긴 변 1600px·webp 280KB 아래로 줄인다. 미니게임 화면은 고를 것만 보내고 결과(사다리 가로줄·당첨 제비·핀 수·주사위)는 응답으로 받아 보여 준다. 편집기에서 장소 이름을 바꾸면 그 장소를 가리키던 인물의 처음 있는 곳·사는 곳도 같이 바뀐다.

**안 한 것**
세계관 신고 버튼, 플레이 중 인물 그림 표정 바꾸기.

## 결과

**동작 확인**
웹 타입 검사·린트 통과. e2e `worlds.spec.ts` 6개 통과(만들기→저장→발행→플레이→답→이벤트 화면 포함).

비주얼노벨 화면은 대사를 한 줄씩 넘기는 방식만 있고 자동 넘김은 없다.
