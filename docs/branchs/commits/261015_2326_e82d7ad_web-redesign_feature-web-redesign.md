## 주 내용

- 디자인 토큰(`globals.css`): 보랏빛 밤·분홍빛 별, `--gradient`·그림자·유리·오로라 배경, 라이트·다크 두 벌. 기존 변수 이름은 그대로 두고 값만 바꿔 모든 화면에 한 번에 적용
- 헤더: 말풍선 로고(`brand-mark.tsx`), 유리 질감, 알약형 메뉴, 비로그인 "시작하기" / 로그인 "캐릭터 만들기"·내 계정
- 홈: 히어로(대화 장식·친밀도 막대), "이어서 대화하기"(최근 대화 3개, 자리표시였던 칸), 초상을 크게 쓴 캐릭터 카드(이름으로 정한 색, 역할·직업 칩)
- 캐릭터 상세: 캐릭터 색 빛 히어로, 큰 초상, 첫 장면 인용 카드, 설정 표 2단
- 채팅: 초상이 붙은 캐릭터 말풍선, 그라데이션 내 말풍선, 입력 중 점 애니메이션, 둥근 입력창·보내기 아이콘(좁은 화면은 아이콘만)
- 대화 목록(초상), 공방·마이페이지·로그인 등 폼·메뉴 서랍·푸터·에이전트, 주요 버튼 일괄 알약형 그라데이션
- `docs/plan/DESIGN.md`: 토큰과 모양 규칙

## 상세

**배경**
사용자 요청("웹 사이트 디자인도 상당히 세련되고 캐릭터 챗봇 컨셉 답게"). 기능 위주의 회색·파랑 기본 화면이었고, 홈은 "진행 중인 캠페인 카드" 자리표시가 남아 있었다.

**변경 범위**
apps/web(globals, 공통 컴포넌트, 홈·상세·채팅·목록·공방·마이페이지·폼 등 CSS 모듈), apps/api(conversations: 목록에 초상 정보), docs/plan/DESIGN.md

**기술 포인트**
- 3,700줄 넘는 CSS 모듈이 이미 `--surface`·`--accent` 같은 변수를 쓰고 있어, 이름은 두고 값과 의미를 다시 잡아 한 번에 바뀌게 했다. 그 위에 화면별로 손봤다.
- 주요 버튼은 "보라 배경 + 흰 글씨" 규칙을 찾아 그라데이션 알약형으로 일괄 변경(14곳)했다.
- 시험이 쓰는 글자·역할·이름(버튼 이름, 목록 li 안의 img 1개 등)은 그대로 지켰다. 좁은 화면의 보내기 버튼은 글자를 숨겨도 화면 읽기 도구는 "보내기"를 읽는다.
- 캡처로 확인하며 고친 것: 모바일 제목이 글자 단위로 끊김 → `word-break: keep-all`, 마이페이지 링크가 한 줄로 붙음 → 알약형 링크, 공방 카드·버튼이 예전 모양.
- 외부 글꼴을 받지 않는다(엄격 CSP의 font-src 'self'와 맞고, 빌드가 네트워크에 기대지 않게). Pretendard가 있으면 쓰고 없으면 시스템 글꼴.

**안 한 것**
공방 편집 화면의 세부 개편(토큰으로 색·버튼만 바뀜), 캐릭터별 배경 이미지, 일러스트 자산
