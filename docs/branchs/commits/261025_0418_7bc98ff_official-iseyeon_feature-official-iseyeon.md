## 주 내용

- 두 번째 공식 캐릭터 이세연(34, 여성, 회장 직속 비서): 호칭 "회장님", 보고체 존댓말, 겉은 차갑고 속은 다정. 아는 것·모르는 것·목표·갈등 씨앗·비밀+해금 조건까지 공식 카드 밀도 기준으로 작성
- 시작 장면은 사용자 요청대로 나레이션(@:)을 먼저 쓰고, 이어서 보고서를 건네는 행동과 대사
- 캐릭터별 추천 프로필(선택): characters.recommendedPersona {name, description}. 대화 화면에 "추천 프로필" 카드 — 그대로 쓰기 / 고쳐서 쓰기(이름·소개 수정) → 내 프로필로 만들고 바로 고름. 같은 이름이 이미 있으면 새로 만들지 않고 고름. 프로필이 하나도 없는 사람의 첫 화면에도 나온다
- 이세연 추천 프로필: 아스테라 그룹 회장 서도현(지어낸 회사 이름)
