## 주 내용

- e2e 화면 서버를 `next dev`에서 운영 빌드로 바꿨다
- 무작위 시간 초과가 사라졌고 시험 시간이 약 11분에서 2.8분으로 줄었다

## 상세

**배경**
전체 e2e가 실행마다 다른 시험에서 시간 초과로 실패해 병합 기준을 채우지 못했다.

**변경 범위**
`e2e/prepare.mjs`, `e2e/servers/web.mjs`, `e2e/servers/console.mjs`, e2e 문서, 디버그 일지.

**기술 포인트**
`next dev`는 화면을 처음 쓸 때 컴파일해 메모리가 모자라면 15초를 넘겼다. 운영 빌드는 운영과 같은 CSP·쿠키로 돌아 더 실제에 가깝다. `E2E_SKIP_BUILD=1`로 빌드를 건너뛸 수 있다.

**안 한 것**
시간 제한 변경, 시험 건너뛰기.

## 결과

**동작 확인**
`npm run test:e2e` 112/112 통과, 종료 코드 0, 시험 2.8분. 남은 RAM 약 400MB에서 돌렸다.

**리스크**
화면을 고친 뒤 일부만 돌릴 때 `E2E_SKIP_BUILD=1`을 쓰면 낡은 빌드를 시험한다.

**후속**
CI 시험 추가.
