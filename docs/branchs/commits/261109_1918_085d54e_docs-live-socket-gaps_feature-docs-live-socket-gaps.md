## 주 내용

웹소켓 이후에도 ‘스트리밍 없음’으로 남아 있던 살아있는 문서를 지금 동작에 맞췄다.

## 상세

### 배경

직전 문서 갱신은 기획서·인수인계·기능 목록·워크플로·포트폴리오 본문까지였다. README, 화면 안내, API 따라 하기, 구조 순서도, FastAPI 경로 표, 앱 README, 기획 스프레드시트는 답이 한 번에 온다고 남아 있었다.

### 변경 범위

- 1:1은 `POST …/chat/live`와 `/ws/chat`, FastAPI `/infer/stream`으로 로컬 토큰을 바로 보여 준다고 적었다.
- 소켓은 글을 옮길 뿐이고 추론을 나누거나 빠르게 하지 않는다고 적었다. 호스팅 모델은 한 덩어리, 월드·명령어는 답이 끝난 뒤다.
- 2026-11-07 속도 실측의 숫자와 문장은 그 날짜의 기록으로 두고, 그 뒤에 화면만 바뀌었다는 줄을 덧붙였다.
- 커밋 기록은 고치지 않았다. 포트폴리오 지식 스냅샷과 문서 파일은 생성 스크립트로 다시 만들었다.

### 기술 포인트

브라우저가 세션 토큰을 모르는 것은 그대로다. 1:1 답만 일회용 표로 Nest 웹소켓에 붙는다. FastAPI는 브라우저가 부르지 않는다.

### 안 한 것

공개 API를 다시 올리지 않았다. 브라우저에서 토큰이 채워지는지는 다시 보지 않았다. 푸시는 하지 않는다.

## 결과

### 동작 확인

문서 대조로 ‘스트리밍 없음’과 ‘브라우저가 API 주소도 토큰도 모른다’가 커밋 기록 외에는 남지 않은 것을 봤다. 모델 호출 시험은 돌리지 않았다.

### 리스크

공개 서버는 이 소켓을 아직 모른다. 문서를 보고 공개 주소에서 토큰이 바로 보일 것으로 기대하면 어긋난다.

### 후속

공개 API를 다시 올린 뒤 STATUS의 그 줄을 닫는다.
