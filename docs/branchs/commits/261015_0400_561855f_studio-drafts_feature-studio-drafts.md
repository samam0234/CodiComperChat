## 상세

**배경**
사용자가 제작(공방) 기능을 요청하며, 앞서 만든 기능들과 조화되게 하라고 했다. 공방 API는 501 뼈대였다. 기획서 §4.1(카드 7층), §5.4(창작자 흐름), §6(공방 레이아웃·필드 의도·UX 장치)을 기준으로 삼았다.

**변경 범위**
apps/api(prisma, studio 모듈), `docs/API_DOCUMENTATION.md`

**기술 포인트**
- 발행 권한: §5.4 "유저 광장이 없으므로 창작 공방은 운영 도구에 가깝다", §9.2 "유저 캐릭터 광장 v1 제외", §9.3 "유저 창작 공방 오픈은 이후". 그래서 초안 작성·테스트는 누구나, 발행은 운영자(ADMIN)만으로 정했다.
- 카드는 JSON 한 덩어리로 저장하고 저장 때마다 정규화한다. 모르는 필드는 버린다.
- 상한은 기획서 수치를 그대로 쓴다: 한 줄 소개 40자(§6.2), 습관 3개·대체 인사 2개·예시 대화 2세트(§4.1).
- 필수 단계는 §6.1 "3, 4, 6"에 목록 노출에 필요한 정체성(이름·한 줄·역할)을 더했다. 비밀은 해금 조건과 쌍이어야 한다(§6.2).
- 토큰 예상은 한국어 글자 2개당 1토큰 근사다(정확한 값이 아닌 무게 감각용, §6.3).

**안 한 것**
- 3턴 테스트·판정, 발행(다음 브랜치), 웹 화면(그 다음)
- 초상 이미지 업로드, "이 칸만 AI로 초안"(§6.1) 버튼, 공개 범위 선택
