## 주 내용

이세연 초상 속 명찰("김서연 비서실")을 지웠다.

## 상세

### 배경

명찰의 이름이 카드 이름(이세연)과 달라 사용자가 가려 달라고 했다.

### 변경 범위

- `lee-seyeon.webp`: 명찰 자리를 위아래·좌우 가장자리 색으로 메우고 가장자리를 부드럽게 섞은 뒤 512px로 다시 저장(약 35KB).
- `CHARACTERS.md`: 명찰을 지웠다는 설명.

### 기술 포인트

OpenCV가 없어 NumPy로 가장자리 색을 보간하고 약한 잡음을 얹었다.

### 안 한 것
